# 📘 Chapter 9.2: Diffusion Models (Stable Diffusion ၏ နောက်ကွယ်မှ အံ့မခန်းနည်းပညာ)

အရင်အခန်းမှာ GANs တွေကို လေ့လာခဲ့ပါတယ်။ GANs တွေက ပုံရိပ်အသစ်တွေ ဖန်တီးရာမှာ တော်ပေမယ့်၊ Training လုပ်ရတာ အရမ်းခက်ခဲပြီး (မကြာခဏ ပျက်ကျတတ်ပြီး) အရည်အသွေးမြင့်တဲ့ ပုံကြီးတွေ ဖန်တီးဖို့ ကန့်သတ်ချက်တွေ ရှိခဲ့ပါတယ်။

၂၀၂၂ ခုနှစ်လောက်မှာတော့ AI လောကကို အကြီးအကျယ် ကိုင်လှုပ်လိုက်တဲ့ **"စာသားရိုက်ထည့်လိုက်ရုံနဲ့ ပန်းချီကားတွေ၊ ဓာတ်ပုံတွေ ဖန်တီးပေးတဲ့ (Text-to-Image)"** နည်းပညာတွေ ပေါ်ထွက်လာပါတယ်။ အဲ့ဒီ AI တွေ အားလုံးရဲ့ အသက်သွေးကြောဟာ GANs မဟုတ်တော့ဘဲ **Diffusion Models** တွေ ဖြစ်သွားပါပြီ။

## 💧 ၁။ Diffusion ဆိုတာ ဘာလဲ? (The Ink Drop Analogy)

ရူပဗေဒမှာ Diffusion ဆိုတာ ရေခွက်ထဲကို မှင်တစ်စက် ချလိုက်ရင်၊ အဲ့ဒီမှင်က ရေခွက်ထဲကို တဖြည်းဖြည်း ပြန့်နှံ့သွားပြီး နောက်ဆုံးမှာ မှင်စက်ပုံစံ ပျောက်သွားတဲ့ သဘောတရားကို ခေါ်ပါတယ်။ 

AI မှာလည်း ဒီသဘောတရားကို အသုံးပြုထားပါတယ်။ အဓိက လုပ်ငန်းစဉ် ၂ ခု ရှိပါတယ်။

### (A) Forward Diffusion (ပုံဖျက်ခြင်း / Noise ထည့်ခြင်း)
ဒါက AI Training လုပ်ဖို့ ပြင်ဆင်တဲ့ အဆင့်ပါ။ ပုံအစစ် (ဥပမာ - ခွေးပုံ) တစ်ပုံကို ယူလိုက်ပါတယ်။ ပြီးရင် အဲ့ဒီပုံပေါ်ကို TV လိုင်းမမိရင် ပေါ်တဲ့ အစက်အပြောက်တွေလိုမျိုး **(Gaussian Noise)** တွေကို အဆင့်ဆင့် (ဥပမာ အဆင့် ၁၀၀၀ လောက်) တဖြည်းဖြည်းချင်း ပေါင်းထည့်လိုက်ပါတယ်။ 
နောက်ဆုံး အဆင့် ၁၀၀၀ လည်း ရောက်ရော ခွေးပုံဆိုတာ လုံးဝ မသိရတော့ဘဲ၊ **"ဆူညံနေတဲ့ အစက်အပြောက် (Pure Noise) ပုံကြီး"** သက်သက်သာ ကျန်ပါတော့တယ်။

### (B) Reverse Diffusion (ပုံပြန်ဖော်ခြင်း / AI သင်ယူခြင်း)
ဒါက တကယ့် AI (Neural Network) အလုပ်လုပ်တဲ့ အဆင့်ပါ။ ပျက်စီးသွားတဲ့ Pure Noise ပုံကြီးကို AI ဆီ ပေးလိုက်ပါတယ်။ AI ရဲ့ တာဝန်က **"ဒီ Noise ပုံကြီးထဲကနေ အစက်အပြောက် (Noise) တွေကို တစ်ဆင့်ချင်းစီ ပြန်ဖယ်ရှား (Denoise) ပြီး မူလ ခွေးပုံအစစ် ပြန်ရအောင် ဖန်တီးပေးဖို့"** ဖြစ်ပါတယ်။

> 🧠 **AI က ဘယ်လို Noise ပြန်ဖယ်လဲ?**
> ဒီနေရာမှာ Chapter 7.2 တုန်းက သင်ခဲ့တဲ့ **U-Net Architecture** ကို အသုံးပြုပါတယ်။ U-Net က Noise ပုံကြီးကို ကြည့်ပြီး "ဒီပုံထဲမှာ Noise ဘယ်လောက် ပါနေလဲ" ဆိုတာကို ခန့်မှန်း (Predict) ပေးပါတယ်။ ပြီးရင် အဲ့ဒီ Noise ကို မူလပုံထဲကနေ ပြန်နှုတ် (Subtract) လိုက်ပါတယ်။ ဒီလို အကြိမ်ကြိမ် နှုတ်သွားခြင်းဖြင့် နောက်ဆုံးမှာ ကြည်လင်ပြတ်သားတဲ့ ပုံအသစ်တစ်ပုံ အံ့မခန်း ထွက်ပေါ်လာပါတော့တယ်။

## ✍️ ၂။ စာသားဖြင့် ပုံဖန်တီးခြင်း (How Text Guides the Generation)

"ရိုးရိုး Noise ထဲကနေ ခွေးပုံထွက်လာတာ ဟုတ်ပါပြီ။ ဒါဆို AI က 'စက်ဘီးစီးနေတဲ့ ခွေး' လို့ ရိုက်ထည့်လိုက်တာကို ဘယ်လိုနားလည်ပြီး ဆွဲပေးတာလဲ?"

ဒီနေရာမှာ AI က U-Net တစ်ခုတည်းကို မသုံးတော့ဘဲ၊ **CLIP (Contrastive Language-Image Pretraining)** လို့ခေါ်တဲ့ အလွန်တော်တဲ့ Transformer မော်ဒယ်တစ်ခုကို တွဲသုံးပါတယ်။
1.  သင်က *"A dog riding a bike"* လို့ စာရိုက်ထည့်လိုက်ပါတယ်။
2.  CLIP မော်ဒယ်က အဲ့ဒီစာသားကို AI နားလည်တဲ့ **Text Embeddings (Vector ဂဏန်းများ)** အဖြစ် ပြောင်းပေးလိုက်ပါတယ်။
3.  Reverse Diffusion (Noise တွေ ပြန်ဖယ်တဲ့) လုပ်ငန်းစဉ်မှာ အဲ့ဒီ စာသားဂဏန်းတွေကို လမ်းညွှန် (Guide) အနေနဲ့ U-Net ဆီကို ထည့်ပေးလိုက်ပါတယ်။ (ဒီနေရာမှာ Chapter 8.1 က Cross-Attention ကို သုံးပါတယ်)။
4.  ဒါကြောင့် U-Net က Noise တွေကို ကျပန်း ဖယ်ရှားတာ မဟုတ်တော့ဘဲ၊ **"စက်ဘီးစီးနေတဲ့ ခွေးပုံစံ ထွက်လာအောင်"** ရည်ရွယ်ချက်ရှိရှိ ပုံဖော်ပေးသွားတာ ဖြစ်ပါတယ်။

## 🚀 ၃။ Stable Diffusion ဆိုတာ ဘာကြောင့် နာမည်ကြီးတာလဲ? (Latent Space)

Diffusion Model တွေက အရမ်းကောင်းပေမယ့် ပြဿနာတစ်ခု ရှိပါတယ်။ `1024x1024` အရွယ်အစားရှိတဲ့ ပုံကြီးတစ်ခုကို Pixel တွေ သိန်းနဲ့ချီပြီး Noise ဖယ်ရတဲ့ (Pixel Space Diffusion) အလုပ်ဟာ အလွန်လေးလံပြီး၊ Google လို Supercomputer ကြီးတွေမှသာ Run နိုင်ပါတယ်။

၂၀၂၂ ခုနှစ်မှာ LMU Munich က သုတေသီတွေနဲ့ Stability AI တို့ပေါင်းပြီး **Stable Diffusion (Latent Diffusion Model)** ကို တီထွင်ခဲ့ပါတယ်။
*   **The Magic:** သူတို့က Noise ဖယ်တဲ့အလုပ်ကို Pixel အကြီးကြီးတွေပေါ်မှာ မလုပ်တော့ပါဘူး။ အရင်ဆုံး ပုံကို Autoencoder သုံးပြီး **အဆ ၆၀ လောက် သေးငယ်သွားတဲ့ `64x64` Latent Space (ကျုံ့ဝင်နေသော နေရာ)** အဖြစ် အရင် ပြောင်းလိုက်ပါတယ်။
*   အဲ့ဒီ `64x64` သေးသေးလေးထဲမှာပဲ Noise တွေထည့်၊ Noise တွေပြန်ဖယ်တဲ့ Diffusion လုပ်ငန်းစဉ် အားလုံးကို အမြန်ဆုံး တွက်ချက်ပါတယ်။ ပြီးမှ အပြင်ကို ပုံကြီးအဖြစ် ပြန်ချဲ့ (Decode) ထုတ်ပေးလိုက်ပါတယ်။
*   ဒါကြောင့် **သာမန် ဂိမ်းဆော့တဲ့ ကွန်ပျူတာ (8GB VRAM ရှိသော GPU) တွေပေါ်မှာတောင် AI ပန်းချီကားတွေကို စက္ကန့်ပိုင်းအတွင်း အခမဲ့ ထုတ်ယူနိုင်သွားပြီး** Open-source AI လောကကို အကြီးအကျယ် တော်လှန်ပစ်နိုင်ခဲ့ပါတယ်။

## 🎛️ ၄။ ခေတ်မီ အသုံးချမှုများ (Inpainting & ControlNet)

Stable Diffusion က ပုံတွေကို ရမ်းဆွဲပေးရုံသာမက၊ လူတွေ လိုချင်သလို အတိအကျ ထိန်းချုပ်နိုင်တဲ့ Tools တွေ အများကြီး ပေါ်လာပါတယ်။

### (A) Inpainting (ပုံကို တစ်စိတ်တစ်ပိုင်း ပြင်ဆင်ခြင်း)
ပုံထဲက ကိုယ်မလိုချင်တဲ့ အစိတ်အပိုင်း (ဥပမာ- မျက်မှန်) ကို Mask ဖြတ် (အရောင်ခြယ်) လိုက်ပါတယ်။ ပြီးရင် prompt မှာ *"နေကာမျက်မှန် (sunglasses)"* လို့ ရိုက်ထည့်လိုက်ရင်၊ AI က ကျန်တဲ့ပုံကို လုံးဝမထိဘဲ၊ အဲ့ဒီ Mask ဧရိယာလေးထဲမှာပဲ နေကာမျက်မှန်ကို သဘာဝကျကျ အစားထိုး ဖန်တီးပေးပါတယ်။

### (B) ControlNet (ပုံသဏ္ဌာန်ကို အတိအကျ ထိန်းချုပ်ခြင်း)
Text prompt တွေက တိကျမှု အားနည်းပါတယ်။ လူတစ်ယောက် လက်မြှောက်နေတဲ့ပုံ လိုချင်တယ်ဆိုရင်၊ ControlNet ကို သုံးရပါတယ်။ 
*   လူရဲ့ အရိုးစု (Pose Skeleton) ကို AI ဆီ ပေးလိုက်ပြီး၊ "ဒီအရိုးစု ပုံစံအတိုင်း စူပါမန်း ဝတ်စုံနဲ့ ဆွဲပေးပါ" လို့ တိတိကျကျ ခိုင်းစေနိုင်တဲ့ အလွန်အစွမ်းထက်တဲ့ နည်းပညာ ဖြစ်ပါတယ်။

## 💻 ၅။ PyTorch နှင့် HuggingFace `diffusers` ဖြင့် ပုံဆွဲကြည့်ခြင်း

Diffusion Model တွေကို Scratch ကနေ ရေးဖို့ အလွန်ခက်ခဲပါတယ်။ ဒါပေမယ့် HuggingFace ရဲ့ `diffusers` library ကိုသုံးရင် Python Code ၄/၅ ကြောင်းနဲ့တင် ပုံရိပ်တွေ ဖန်တီးနိုင်ပါတယ်။

**Installation:**
```bash
pip install diffusers transformers accelerate
```

**Code Example:**
```python
import torch
from diffusers import StableDiffusionPipeline

def generate_image():
    # ၁။ HuggingFace မှ Stable Diffusion Model ကို ဒေါင်းလုဒ်ဆွဲ၍ ခေါ်ယူခြင်း
    model_id = "runwayml/stable-diffusion-v1-5"
    
    # GPU ဖြင့် မြန်ဆန်စွာ Run နိုင်ရန် float16 ဖြင့် ခေါ်ယူသည်
    pipe = StableDiffusionPipeline.from_pretrained(model_id, torch_dtype=torch.float16)
    
    # Model ကို GPU ပေါ်သို့ ရွှေ့ခြင်း
    device = "cuda" if torch.cuda.is_available() else "cpu"
    pipe = pipe.to(device)

    # ၂။ ကိုယ်လိုချင်သော ပုံ၏ စာသား (Prompt) ရေးသားခြင်း
    prompt = "A futuristic cyberpunk city at night, neon lights, highly detailed, 4k resolution"

    print(f"Generating image for: '{prompt}'...")

    # ၃။ Diffusion လုပ်ငန်းစဉ် စတင်ခြင်း (စက္ကန့်အနည်းငယ် ကြာနိုင်ပါသည်)
    # num_inference_steps=50 ဆိုသည်မှာ Noise များကို အဆင့် ၅၀ ဖြင့် တဖြည်းဖြည်း ဖယ်ရှားမည်ဟု ဆိုလိုသည်
    image = pipe(prompt, num_inference_steps=50).images[0]

    # ၄။ ရရှိလာသော ပုံကို သိမ်းဆည်းခြင်း
    image.save("cyberpunk_city.png")
    print("Image successfully generated and saved as cyberpunk_city.png! 🎉")

if __name__ == "__main__":
    generate_image()
```

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **Diffusion Models** သည် ပုံများကို အစက်အပြောက်များ (Noise) အဖြစ် ဖျက်ဆီးပြီးနောက်၊ ယင်း Noise များကို U-Net အသုံးပြု၍ တစ်ဆင့်ချင်း ပြန်လည်ဖယ်ရှားကာ ပုံရိပ်သစ်များ ဖန်တီးသော စနစ်ဖြစ်သည်။
2.  **Text-to-Image** စနစ်တွင် သုံးစွဲသူ ရိုက်ထည့်လိုက်သော စာသားကို CLIP မော်ဒယ်ဖြင့် နားလည်အောင် ပြောင်းလဲပြီး Denoising လုပ်ငန်းစဉ်ကို လမ်းညွှန်ပေးသည်။
3.  **Stable Diffusion** သည် ကြီးမားသော Pixel များအစား အလွန်သေးငယ်သော (Latent Space) တွင် တွက်ချက်သဖြင့် သာမန် ကွန်ပျူတာများဖြင့်ပင် အသုံးပြုနိုင်သော တော်လှန်ရေးတစ်ခု ဖြစ်သည်။
4.  **ControlNet** နှင့် **Inpainting** တို့သည် ဖန်တီးမှုလုပ်ငန်းစဉ်ကို မိမိစိတ်ကြိုက် အတိအကျ ထိန်းချုပ်နိုင်သော အဆင့်မြင့် ကိရိယာများ ဖြစ်ကြသည်။
