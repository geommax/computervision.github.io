# 📘 Chapter 6.1: Object Detection Fundamentals (အရာဝတ္ထုရှာဖွေခြင်း အခြေခံသဘောတရားများ)

အရင် Part 2 တုန်းက သင်ခဲ့တဲ့ Classification မော်ဒယ်တွေဟာ ပုံတစ်ပုံကို ကြည့်ပြီး **"ဒီပုံထဲမှာ ခွေးပါလား၊ ကြောင်ပါလား" (What is in the image?)** ဆိုတာကိုပဲ ပြောပြနိုင်ပါတယ်။ ဒါပေမယ့် လက်တွေ့ကမ္ဘာမှာ CCTV ကနေ လူဘယ်နှစ်ယောက် လမ်းဖြတ်ကူးနေလဲ၊ Self-driving Car တွေမှာ ကားတွေ ဘယ်နားမှာ ရှိနေလဲဆိုတာကို သိဖို့အတွက် **"ဘယ်နေရာမှာ ရှိသလဲ" (Where is it?)** ဆိုတာကိုပါ ထောက်လှမ်းပေးနိုင်ဖို့ လိုအပ်လာပါတယ်။

ဒီလို "ဘာအရာဝတ္ထုလဲ" ဆိုတာရော၊ "ဘယ်နေရာမှာ ရှိလဲ" ဆိုတာကိုပါ တစ်ပြိုင်နက်တည်း ရှာဖွေပေးတဲ့ နည်းပညာကို **Object Detection** လို့ ခေါ်ပါတယ်။

## 🆚 ၁။ Classification vs. Object Detection ဘာကွာသလဲ?

1. **Image Classification:**
   * ပုံတစ်ပုံလုံးကို ခြုံငုံကြည့်ပြီး အဖြေတစ်ခုတည်း (Label တစ်ခုတည်း) ထုတ်ပေးပါတယ်။
   * ပုံထဲမှာ ခွေးနဲ့ကြောင် အတူတူပါနေရင်တောင် ရာခိုင်နှုန်းအများဆုံး တစ်ခုကိုပဲ ဆုံးဖြတ်လေ့ရှိပါတယ်။
   * Location (နေရာ) ကို မသိပါဘူး။
2. **Object Detection:**
   * ပုံတစ်ပုံတည်းထဲမှာရှိတဲ့ **အရာဝတ္ထုများစွာ (Multiple Objects)** ကို တစ်ပြိုင်နက်တည်း ရှာဖွေပေးနိုင်ပါတယ်။
   * တွေ့ရှိတဲ့ အရာဝတ္ထုတစ်ခုချင်းစီကို **လေးထောင့်ဘောင် (Bounding Box)** ခတ်ပြပါတယ်။
   * Box တစ်ခုချင်းစီအတွက် ဘာအရာဝတ္ထုလဲ ဆိုတဲ့ Class Label နဲ့ သေချာမှု ရာခိုင်နှုန်းကိုပါ ထုတ်ပေးပါတယ်။

## 🏗️ ၂။ Object Detection ၏ အဓိက Architectures ၃ မျိုး (အရေးကြီးဆုံး)

Object Detection ကို ဘယ်လိုနည်းလမ်းနဲ့ တွက်ချက်ရှာဖွေမလဲ ဆိုတဲ့အပေါ် မူတည်ပြီး အဓိကအားဖြင့် မျိုးဆက် ၃ မျိုး ခွဲခြားနိုင်ပါတယ်။

### (A) Two-Stage Detectors (အဆင့်နှစ်ဆင့်ပါသော စနစ်)
* **အလုပ်လုပ်ပုံ:** နာမည်အတိုင်း အဆင့် ၂ ဆင့် ခွဲလုပ်ပါတယ်။ 
  * **Stage 1 (Region Proposal):** ပုံထဲမှာ အရာဝတ္ထုတွေ ရှိနိုင်လောက်မယ့် နေရာလွတ် (Regions) ထောင်ပေါင်းများစွာကို အကြမ်းဖျင်း အရင်လိုက်ရှာပါတယ်။
  * **Stage 2 (Classification):** အဲ့ဒီ ရလာတဲ့ နေရာလေးတွေကိုမှ တစ်ခုချင်းစီ CNN ထဲထည့်ပြီး ဒါဟာ ခွေးလား၊ ကြောင်လား သေချာအောင် ပြန်လည်စစ်ဆေးပါတယ်။
* **ဥပမာ မော်ဒယ်များ:** R-CNN, Fast R-CNN, **Faster R-CNN**
* **အားသာချက် / အားနည်းချက်:** အလွန်တိကျ (Accuracy ကောင်း) ပေမယ့်၊ အဆင့် ၂ ဆင့် လုပ်ရတဲ့အတွက် **အလွန်နှေးကွေးပြီး Real-time (ဥပမာ - CCTV, Webcam) မှာ သုံးဖို့ မသင့်လျော်ပါဘူး။**

### (B) One-Stage Detectors (အဆင့်တစ်ဆင့်တည်းဖြင့် ပြီးပြည့်စုံသော စနစ်)
* **အလုပ်လုပ်ပုံ:** ပုံကို ဇယားကွက် (Grid) တွေ အဖြစ်ပိုင်းဖြတ်လိုက်ပါတယ်။ ပြီးတာနဲ့ အဆင့် ၂ ဆင့် ခွဲမနေတော့ဘဲ၊ CNN ကနေတစ်ဆင့် **Bounding Box နေရာတွေရော၊ ဘာအရာဝတ္ထုလဲဆိုတဲ့ Class တွေရောကို တစ်ချက်တည်း (Single Pass) နဲ့ တိုက်ရိုက် ခန့်မှန်းထုတ်ပေးလိုက်ပါတယ်။**
* **ဥပမာ မော်ဒယ်များ:** **YOLO (You Only Look Once)**, SSD (Single Shot Detector)
* **အားသာချက် / အားနည်းချက်:** တွက်ချက်ရတာ အလွန်မြန်ဆန်တဲ့အတွက် **Real-time Video တွေ၊ ဖုန်းတွေမှာ အသုံးပြုဖို့ အကောင်းဆုံး (Industry Standard) ဖြစ်ပါတယ်။** (ယခင်က Accuracy နည်းနည်းကျတတ်ပေမယ့် ယနေ့ခေတ် YOLOv8/v10 တွေမှာတော့ Two-Stage တွေလောက်နီးပါး တိကျလာပါပြီ)။

### (C) End-to-End Detection (ခေတ်သစ် Transformer အခြေခံ စနစ်)
* **အလုပ်လုပ်ပုံ:** အထက်က One-Stage ရော Two-Stage မှာပါ NMS (Non-Maximum Suppression) လိုမျိုး လူကရေးပေးရတဲ့ Post-processing အဆင့်တွေ ပါဝင်နေပါသေးတယ်။ End-to-End စနစ်ကတော့ အဲ့ဒါတွေ အားလုံးကို ဖယ်ရှားလိုက်ပြီး၊ ပုံကို ထည့်ပေးလိုက်တာနဲ့ Transformer ရဲ့ Attention စနစ်ကို သုံးပြီး **အရာဝတ္ထုတွေရဲ့ Box နဲ့ Class တွေကို ဘာအကူအညီမှမပါဘဲ (Truly End-to-End) အတိအကျ ထုတ်ပေးတဲ့ စနစ်** ဖြစ်ပါတယ်။
* **ဥပမာ မော်ဒယ်များ:** **DETR (DEtection TRansformer)**
* **အားသာချက် / အားနည်းချက်:** NMS မလိုတော့တဲ့အတွက် Architecture ပိုရှင်းလင်းသွားပါတယ်။ သို့သော် Train ရန် အချိန်ပိုကြာပြီး၊ Model အရွယ်အစား ကြီးမားလေ့ရှိပါတယ်။

## 🎯 ၃။ Object Detection ၏ ရလဒ် ၃ ခု (The Outputs)

AI က အရာဝတ္ထုတစ်ခုကို တွေ့ပြီဆိုရင် အဓိက ဂဏန်း ၃ မျိုး ပြန်ထုတ်ပေးပါတယ်။

1. **Bounding Box Coordinates:** အရာဝတ္ထုကို ဝိုင်းပြမယ့် လေးထောင့်ဘောင်ပါ။ ပုံစံ ၂ မျိုးနဲ့ ထုတ်ပေးလေ့ရှိပါတယ်။
   * `(x_min, y_min, x_max, y_max)`: ဘယ်-အပေါ်ထောင့် နှင့် ညာ-အောက်ထောင့်။
   * `(x_center, y_center, width, height)`: ဗဟိုချက် နှင့် ဘောင်၏ အလျား/အနံ (YOLO တွင် အသုံးများသည်)။
2. **Confidence Score:** "ဒီဘောင်ထဲမှာ အရာဝတ္ထုတစ်ခု သေချာပေါက် ရှိနေတယ်ဆိုတာ ဘယ်လောက်ရာခိုင်နှုန်း ယုံကြည်သလဲ" (ဥပမာ - $0.95$ သို့မဟုတ် $95\%$)။
3. **Class Label:** အဲ့ဒီ အရာဝတ္ထုက ဘာလဲ ဆိုတာပါ (ဥပမာ - `0`=Person, `1`=Car)။

---

## 📐 ၄။ IoU (Intersection over Union) ဆိုတာ ဘာလဲ?

AI က ဆွဲပေးလိုက်တဲ့ Bounding Box (Predicted Box) ဟာ၊ လူက ရေးဆွဲပေးထားတဲ့ အဖြေမှန် Bounding Box (Ground Truth Box) နဲ့ **ဘယ်လောက်တောင် ထပ်တူကျသလဲ (ဘယ်လောက် တိကျသလဲ)** ဆိုတာကို တိုင်းတာတဲ့ ပုံသေနည်း ဖြစ်ပါတယ်။

*   **Intersection (ထပ်နေသော ဧရိယာ):** Box နှစ်ခု ထပ်နေတဲ့ အလယ်က ဧရိယာ။
*   **Union (စုစုပေါင်း ဧရိယာ):** Box နှစ်ခုလုံး ပေါင်းထားတဲ့ စုစုပေါင်း ဧရိယာ။
*   **IoU ဖော်မြူလာ:** $\text{IoU} = \frac{\text{Intersection Area}}{\text{Union Area}}$

**IoU တန်ဖိုးသည် 0 မှ 1 အတွင်း ရှိပါသည်။**
*   **IoU = 0:** Box နှစ်ခု လုံးဝ မထိပါ (လုံးဝမှားယွင်းနေသည်)။
*   **IoU = 1:** Box နှစ်ခု ကွက်တိ ထပ်တူကျသည် (100% မှန်ကန်သည်)။
*   များသောအားဖြင့် **IoU 0.5 (50%) ထက်ကျော်လျှင်** AI သည် နေရာကို မှန်ကန်စွာ ရှာတွေ့သည် (True Positive) ဟု သတ်မှတ်လေ့ရှိပါသည်။

## ✂️ ၅။ NMS (Non-Maximum Suppression)

YOLO လို One-Stage Detector တွေကို အသုံးပြုတဲ့အခါ AI က ခွေးတစ်ကောင်တည်းကိုပဲ **"ဒီနားမှာ ခွေးရှိတယ်"** ဆိုပြီး Bounding Box တွေ ၅ ခု၊ ၆ ခုလောက် ထပ်ပြီး (Duplicate) ဆွဲပြတတ်တဲ့ ပြဿနာ ရှိပါတယ်။ ဒါကို ရှင်းလင်းဖို့ NMS ကို သုံးရပါတယ်။

**NMS အလုပ်လုပ်ပုံ:**
1. အရာဝတ္ထုတစ်ခုတည်းပေါ်မှာ ထပ်နေတဲ့ Box တွေထဲကမှ **Confidence Score အမြင့်ဆုံး (ဥပမာ 98%)** ရှိတဲ့ Box ကို ရွေးထုတ်လိုက်ပါတယ်။ (Max ကို ယူသည်)။
2. အဲ့ဒီ ရွေးလိုက်တဲ့ Box နဲ့ **IoU တန်ဖိုး အရမ်းများနေတဲ့ (အများကြီး ထပ်နေတဲ့)** ကျန်တဲ့ Box အားလုံးကို ပယ်ဖျက် (Suppress) ပစ်လိုက်ပါတယ်။
3. ရလဒ်အနေနဲ့ ခွေးတစ်ကောင်ကို Box တစ်ခုတည်းသာ ကျန်ရှိပါတော့တယ်။

*(မှတ်ချက် - DETR ကဲ့သို့ End-to-End Detector များတွင် ဤအဆင့် မလိုအပ်တော့ပါ)*။

## 🏆 ၆။ mAP (Mean Average Precision) ဖြင့် Model ကို အမှတ်ပေးခြင်း

Classification တုန်းက Accuracy (ရာခိုင်နှုန်း) နဲ့ တိုင်းတာသလိုမျိုး၊ Object Detection မှာ Model ကောင်း/မကောင်းကို တိုင်းတာတဲ့ Ultimate Metric ကတော့ **mAP (Mean Average Precision)** ပဲ ဖြစ်ပါတယ်။ 

mAP ဟာ တွက်ချက်ရတာ အလွန်ရှုပ်ထွေးပါတယ်။ ဘာလို့လဲဆိုတော့ သူက "အရာဝတ္ထုကို မှန်အောင် ခန့်မှန်းနိုင်သလား (Precision & Recall)" ဆိုတာကိုရော၊ "Bounding Box နေရာကွက်တိ ကျရဲ့လား (IoU)" ဆိုတာကိုပါ ပေါင်းစပ်ပြီး တွက်ချက်ရလို့ပါ။

*   **mAP@0.5:** IoU 0.5 (50%) အထက် မှန်တာကိုပဲ အဖြေမှန်လို့ သတ်မှတ်ပြီး တွက်ထားသော mAP အမှတ်။
*   **mAP@0.5:0.95 (သို့မဟုတ် mAP မျှသာ):** IoU 0.5 ကနေ 0.95 အထိကို 0.05 စီခြားပြီး အမှတ်တွေ တွက်ကာ ပျမ်းမျှယူထားခြင်း ဖြစ်ပါတယ်။ ဒါဟာ **COCO Dataset** မှာ သုံးတဲ့ အလွန်တင်းကျပ်တဲ့ စံချိန်စံညွှန်း ဖြစ်ပြီး၊ ဒီအမှတ် 50% (0.5) ကျော်ရဖို့ဆိုတာ Model တော်တော်များများအတွက် အလွန်ခက်ခဲပါတယ်။

## 📝 အနှစ်ချုပ် (Key Takeaways)
1. **Object Detection** သည် ပုံထဲရှိ အရာဝတ္ထုများ၏ "အမျိုးအစား" နှင့် "တည်နေရာ (BBox)" ကိုပါ တစ်ပြိုင်နက်တည်း ရှာဖွေပေးသည်။
2. **Two-Stage** (Faster R-CNN) သည် တိကျသော်လည်း နှေးသည်။ **One-Stage** (YOLO) သည် မြန်ဆန်၍ Real-time တွင် အသုံးများသည်။ **End-to-End** (DETR) သည် NMS မလိုဘဲ တိုက်ရိုက် ထုတ်ပေးသော ခေတ်သစ်စနစ် ဖြစ်သည်။
3. **IoU (Intersection over Union)** သည် Bounding Box များ မည်မျှ တိကျစွာ ထပ်တူကျသည်ကို တိုင်းတာသော ပုံသေနည်းဖြစ်သည်။
4. **NMS (Non-Maximum Suppression)** သည် အရာဝတ္ထုတစ်ခုတည်းပေါ်တွင် ထပ်နေသော Box များကို ဖယ်ရှားပေးသော လုပ်ငန်းစဉ်ဖြစ်သည်။
5. **mAP** သည် Object Detection မော်ဒယ်များ၏ စွမ်းဆောင်ရည်ကို တိုင်းတာသော အမြင့်ဆုံး စံချိန်စံညွှန်း (Metric) ဖြစ်သည်။
