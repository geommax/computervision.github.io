# 📘 Chapter 3.1: Image Filtering & Blurring (ပုံရိပ်များကို ချောမွေ့စေခြင်းနှင့် Noise ဖယ်ရှားခြင်း)

လက်တွေ့ကမ္ဘာမှာ ကင်မရာတွေကနေ ရိုက်ကူးလိုက်တဲ့ ပုံတွေဟာ အမြဲတမ်း ရှင်းလင်းပြတ်သားမနေပါဘူး။ အလင်းရောင်အားနည်းတဲ့အခါမျိုး၊ ကင်မရာဆင်ဆာ မကောင်းတဲ့အခါမျိုးတွေမှာ ပုံတွေပေါ်မှာ အစက်အပြောက်ငယ်လေးတွေ (Noise) ပါလာတတ်ပါတယ်။ 

ဒီ Noise တွေဟာ နောက်ပိုင်းမှာ အနားသတ်မျဉ်း (Edges) တွေ ရှာတဲ့အခါ AI တွေကို အလွန်ဒုက္ခပေးပါတယ်။ ဒါကြောင့် ပုံတစ်ပုံကို စတင်ပြီး မခွဲခြမ်းစိတ်ဖြာခင်မှာ **Blur လုပ်ခြင်း (ဝါးအောင်လုပ်ခြင်း/ချောမွေ့စေခြင်း)** ကို မဖြစ်မနေ (Preprocessing Step) အနေနဲ့ ပြုလုပ်ပေးရပါတယ်။

ဒီအခန်းမှာ ပုံတွေကို Blur လုပ်တဲ့ အဓိက နည်းလမ်း ၄ မျိုးကို လေ့လာသွားပါမယ်။

---

## 🧠 Image Filtering နှင့် Kernel ဆိုတာ ဘာလဲ?

Blur လုပ်တာကို နားလည်ဖို့ **Kernel (သို့မဟုတ်) Filter** ဆိုတဲ့ သဘောတရားကို အရင်သိဖို့လိုပါတယ်။
Kernel ဆိုတာ ပုံမှန်အားဖြင့် `3x3` သို့မဟုတ် `5x5` အရွယ်အစားရှိတဲ့ Matrix (ဇယားကွက်) ငယ်လေးတစ်ခု ဖြစ်ပါတယ်။

အဲ့ဒီ Kernel လေးဟာ မူရင်းပုံကြီးပေါ်မှာ ဘယ်ဘက်အပေါ်ထောင့်ကနေ ညာဘက်အောက်ထောင့်အထိ တစ်ကွက်ချင်းစီ ရွေ့လျားသွားပါတယ်။ ရွေ့သွားတဲ့ နေရာတိုင်းမှာ သူ့အောက်မှာရောက်နေတဲ့ Pixel တွေရဲ့ တန်ဖိုးတွေကို တွက်ချက်ပြီး၊ အလယ်ဗဟိုက Pixel ရဲ့ တန်ဖိုးအသစ်ကို အစားထိုး ဖန်တီးပေးပါတယ်။ 

*(မှတ်ချက် - ဒီသဘောတရားကို Convolution လို့ခေါ်ပြီး နောက်ပိုင်းမှာ သင်ရမယ့် Convolutional Neural Network (CNN) တွေရဲ့ အဓိက အသက်သွေးကြောပဲ ဖြစ်ပါတယ်။)*

---

## 🌫️ ၁။ Average Blurring (သာမန် ဝါးခြင်း)

အလွယ်ကူဆုံး Blur လုပ်တဲ့ နည်းလမ်းပါ။ Kernel အောက်မှာရှိတဲ့ Pixel တန်ဖိုး အားလုံးကို ပေါင်းပြီး၊ အရေအတွက်နဲ့ စားကာ (Average ယူပြီး) အလယ်ဗဟိုမှာ အစားထိုးလိုက်တာ ဖြစ်ပါတယ်။

```python
import cv2

image = cv2.imread('test.jpg')

# 5x5 Kernel ကို အသုံးပြု၍ Average Blur လုပ်ခြင်း
# Kernel အရွယ်အစား ကြီးလေလေ၊ ပို၍ ဝါးလေလေ ဖြစ်သည်
avg_blur = cv2.blur(image, (5, 5))
```

---

## 🌫️ ၂။ Gaussian Blurring (သဘာဝကျကျ ဝါးခြင်း)

Average Blur က အရမ်းကြမ်းတမ်းပါတယ်။ Gaussian Blur ကတော့ အလယ်ဗဟိုမှာရှိတဲ့ Pixel ကို အရေးအကြီးဆုံး (Weight အများဆုံး) အဖြစ် သတ်မှတ်ပြီး၊ အစွန်အဖျားက Pixel တွေကိုတော့ အရေးပါမှု လျှော့ချတွက်ချက်ပါတယ်။ ဒါကြောင့် ထွက်လာတဲ့ပုံက မျက်စိနဲ့ကြည့်ရင် ပိုပြီး သဘာဝကျကျ ဝါးသွားပါတယ်။ အများဆုံး အသုံးပြုတဲ့ နည်းလမ်းဖြစ်ပါတယ်။

```python
# 5x5 Kernel ကို အသုံးပြု၍ Gaussian Blur လုပ်ခြင်း
# တတိယ parameter '0' သည် Standard Deviation တန်ဖိုးဖြစ်ပြီး 0 ထားပါက အလိုအလျောက် တွက်ချက်ပေးသည်
gaussian_blur = cv2.GaussianBlur(image, (5, 5), 0)
```
> 💡 **မှတ်ချက်:** Kernel အရွယ်အစား `(ksize)` ကို သတ်မှတ်တဲ့အခါ အမြဲတမ်း **မဂဏန်း (Odd Numbers: 3, 5, 7, 9...)** ကိုသာ အသုံးပြုရပါမယ်။ 그래မှသာ အလယ်ဗဟို (Center Pixel) ကို အတိအကျ သတ်မှတ်နိုင်မှာ ဖြစ်ပါတယ်။

---

## 🧂 ၃။ Median Blurring (ဆားနှင့်ငရုတ်ကောင်း Noise ဖယ်ရှားခြင်း)

တစ်ခါတစ်ရံ ပုံတွေထဲမှာ အဖြူစက်၊ အမည်းစက်လေးတွေ (Salt-and-Pepper Noise) အများကြီး ပါလာတတ်ပါတယ်။ ဒီလိုအချိန်မှာ Median Blur က အကောင်းဆုံးပါ။ သူက Kernel အောက်က Pixel တွေအားလုံးကို အစဉ်လိုက်စီပြီး၊ အလယ်တည့်တည့်က တန်ဖိုး (Median Value) ကို ယူပါတယ်။ ဒါကြောင့် ဆိုးရွားတဲ့ အစက်အပြောက်တွေကို အထိရောက်ဆုံး ဖျောက်ပစ်နိုင်ပါတယ်။

```python
# 5 ဆိုသည်မှာ 5x5 Kernel ကို ဆိုလိုသည်
median_blur = cv2.medianBlur(image, 5)
```

---

## 📸 ၄။ Bilateral Filtering (အနားသတ်များမပျောက်စေဘဲ ဝါးခြင်း)

အပေါ်က နည်းလမ်း ၃ ခုလုံးရဲ့ အားနည်းချက်က ပုံကို ဝါးလိုက်ရင် အရာဝတ္ထုတွေရဲ့ အနားသတ်မျဉ်း (Edges) တွေပါ လိုက်ပြီး ဝါးသွားတာပါပဲ။ 

Bilateral Filter ကတော့ ခြားနားပါတယ်။ သူက ပုံကို ကြည့်ကောင်းအောင် ချောမွေ့စေပေမယ့်၊ **အရေးကြီးတဲ့ အနားသတ်မျဉ်း (Edges) တွေကိုတော့ ပြတ်ပြတ်သားသား ချန်ထားခဲ့ပါတယ်။** ဒါကြောင့် ဖုန်းတွေမှာပါတဲ့ **Beauty Mode (မျက်နှာကို ချောမွေ့စေသော ကင်မရာများ)** တွေဟာ ဒီ Bilateral Filter ကို အခြေခံပြီး အသုံးပြုကြတာ ဖြစ်ပါတယ်။

```python
# d=9 (Pixel neighborhood diameter), sigmaColor=75, sigmaSpace=75
bilateral_filter = cv2.bilateralFilter(image, 9, 75, 75)
```
*(အားနည်းချက် - တွက်ချက်ရတာ ရှုပ်ထွေးတဲ့အတွက် တခြား Blur တွေထက် အနည်းငယ် ပိုနှေးပါတယ်။)*

---

## 🧩 ၅။ အစအဆုံး နှိုင်းယှဉ်ပြသခြင်း (Complete Comparison Example)

ဒီနည်းလမ်း ၄ မျိုး ကွာခြားသွားပုံကို မြင်သာအောင် Code တစ်ခုတည်းမှာ ပေါင်းရေးပြီး ယှဉ်ကြည့်ကြပါမယ်။

```python
import cv2
import numpy as np

def main():
    # ပုံဖတ်ခြင်း (အနည်းငယ် Noise ပါသော ပုံဆိုလျှင် ပိုသိသာသည်)
    image = cv2.imread('test.jpg')
    if image is None:
        print("Image not found!")
        return
        
    image = cv2.resize(image, (400, 400)) # ကြည့်ရလွယ်အောင် အရွယ်အစား ညှိခြင်း

    # ၁။ Average Blur
    avg_blur = cv2.blur(image, (5, 5))

    # ၂။ Gaussian Blur
    gaussian = cv2.GaussianBlur(image, (5, 5), 0)

    # ၃။ Median Blur
    median = cv2.medianBlur(image, 5)

    # ၄။ Bilateral Filter
    bilateral = cv2.bilateralFilter(image, 9, 75, 75)

    # မျက်နှာပြင်တွင် ပြသရန် ပုံများကို ဘေးတိုက် (Horizontal) ဆက်ခြင်း
    top_row = np.hstack((image, avg_blur, gaussian))
    bottom_row = np.hstack((image, median, bilateral)) # နှိုင်းယှဉ်ရလွယ်ရန် မူရင်းပုံကိုပါ ပြန်ထည့်ထားသည်

    cv2.imshow('Top: Original | Average | Gaussian', top_row)
    cv2.imshow('Bottom: Original | Median | Bilateral', bottom_row)

    cv2.waitKey(0)
    cv2.destroyAllWindows()

if __name__ == "__main__":
    main()
```

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **Filtering/Blurring** သည် နောက်ပိုင်း Computer Vision လုပ်ငန်းစဉ်များ (ဥပမာ- Edge Detection) မပြုလုပ်မီ Noise များကို ဖယ်ရှားရန်အတွက် မရှိမဖြစ်လိုအပ်သော အဆင့်ဖြစ်သည်။
2.  **Gaussian Blur (`cv2.GaussianBlur`)** ကို အထွေထွေ Noise ဖယ်ရှားခြင်းများအတွက် အများဆုံး အသုံးပြုသည်။
3.  **Median Blur (`cv2.medianBlur`)** သည် ပုံပေါ်ရှိ အဖြူစက်၊ အမည်းစက် (Salt-and-pepper) များကို ဖျောက်ရာတွင် အကောင်းဆုံးဖြစ်သည်။
4.  **Bilateral Filter (`cv2.bilateralFilter`)** သည် ပုံကိုချောမွေ့စေသော်လည်း အရေးကြီးသော အနားသတ်များကို ထိန်းသိမ်းထားနိုင်သဖြင့် Beauty mode များတွင် အသုံးပြုသည်။
5.  Kernel အရွယ်အစား `(ksize)` ကို အမြဲတမ်း **မဂဏန်း (Odd number)** ဖြင့်သာ သတ်မှတ်ရသည်။
