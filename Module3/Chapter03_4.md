# 📘 Chapter 3.4: Traditional Feature Extraction (ရိုးရာ Feature ထုတ်ယူခြင်း နည်းပညာများ အကျဉ်းချုပ်)

ယနေ့ခေတ်မှာ လူမျက်နှာ ရှာတာဖြစ်ဖြစ်၊ ခွေးနဲ့ကြောင် ခွဲခြားတာဖြစ်ဖြစ် Deep Learning (CNN, YOLO) တွေကိုပဲ သုံးကြပေမယ့်၊ လွန်ခဲ့တဲ့ ၁၀ နှစ်ကျော်ကာလတွေမှာ AI Model တွေ မရှိသေးပါဘူး။ 

အဲ့ဒီခေတ်က ကွန်ပျူတာကို **"ဒါကတော့ မျက်နှာဖြစ်တယ်"** လို့ သိအောင် သင်ပေးဖို့အတွက်၊ လူသားပညာရှင်တွေ ကိုယ်တိုင်က **"မျက်လုံးဆိုတာ အမည်းရောင်ဖြစ်တယ်၊ ပါးပြင်က လင်းတယ်၊ နှာခေါင်းက ချွန်တယ်"** စတဲ့ သင်္ချာပုံသေနည်းတွေ (Hand-crafted Features) ကို အပင်ပန်းခံ ရေးသားခဲ့ကြရပါတယ်။ အဲ့ဒီလို ပုံထဲက ထူးခြားတဲ့ အမှတ်အသားတွေကို တွက်ထုတ်တဲ့ လုပ်ငန်းစဉ်ကို **Feature Extraction** လို့ ခေါ်ပါတယ်။

ဒီအခန်းမှာ အထင်ရှားဆုံး Traditional Method ၂ ခုဖြစ်တဲ့ Haar Cascades နဲ့ ORB/SIFT တို့အကြောင်းကို ဗဟုသုတအနေနဲ့ အကျဉ်းချုပ် လေ့လာသွားပါမယ်။

## 👤 ၁။ Haar Cascades (အစောပိုင်းခေတ် မျက်နှာရှာဖွေခြင်း)

၂၀၀၁ ခုနှစ်မှာ Viola နဲ့ Jones ဆိုတဲ့ ပညာရှင်နှစ်ယောက်က **Haar Cascade** ဆိုတဲ့ Face Detection နည်းပညာကို တီထွင်ခဲ့ပါတယ်။ ဒါဟာ ဒစ်ဂျစ်တယ်ကင်မရာတွေမှာ မျက်နှာကို လေးထောင့်ဘောင်လေးတွေ အလိုအလျောက် ပေါ်လာအောင် လုပ်ပေးနိုင်ခဲ့တဲ့ ကမ္ဘာ့ပထမဆုံး တော်လှန်ရေး နည်းပညာတစ်ခု ဖြစ်ပါတယ်။

**ဘယ်လိုအလုပ်လုပ်သလဲ?**
သူက မျက်နှာရဲ့ အလင်းအမှောင် ကွာခြားချက်တွေကို အခြေခံပါတယ်။ ဥပမာ - 
*   လူတွေရဲ့ မျက်လုံးနေရာဟာ ပါးပြင်ထက်စာရင် ပိုပြီး မှောင်/မည်း နေလေ့ရှိပါတယ်။
*   နှာခေါင်းတံ နေရာဟာ ဘေးဘက်တွေထက် ပိုလင်းနေလေ့ ရှိပါတယ်။
ဒီလို အမည်းနဲ့အဖြူ လေးထောင့်ကွက် (Haar Features) လေးတွေကို ပုံပေါ်မှာ ရွှေ့လျားပြီး တိုက်စစ်ကာ မျက်နှာ ဟုတ်/မဟုတ် ဆုံးဖြတ်တာ ဖြစ်ပါတယ်။

### 💻 Haar Cascade ဖြင့် Face Detection စမ်းသပ်ကြည့်ခြင်း
OpenCV မှာ Haar Cascade ကို အသုံးပြုဖို့ အလွန်လွယ်ကူပါတယ်။ Training လုပ်ပြီးသား `XML` file တွေကို OpenCV က အသင့် ထည့်သွင်းပေးထားပါတယ်။

```python
import cv2

def detect_face():
    # OpenCV တွင် အသင့်ပါဝင်သော Face Detection XML ဖိုင်ကို ခေါ်ယူခြင်း
    face_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')

    image = cv2.imread('people.jpg')
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

    # မျက်နှာများကို ရှာဖွေခြင်း (scaleFactor နှင့် minNeighbors ဖြင့် ချိန်ညှိနိုင်သည်)
    faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5)

    # တွေ့ရှိသော မျက်နှာများကို ဘောင်ခတ်ခြင်း
    for (x, y, w, h) in faces:
        cv2.rectangle(image, (x, y), (x+w, y+h), (0, 255, 0), 2)

    cv2.imshow('Face Detection', image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

detect_face()
```
*(အားနည်းချက် - မျက်နှာကို တည့်တည့်ကြည့်နေမှသာ အလုပ်လုပ်လေ့ရှိပြီး၊ ဘေးတိုက်လှည့်နေလျှင် သို့မဟုတ် အလင်းရောင် အလွန်နည်းနေလျှင် မရှာနိုင်တော့ပါ။ ဒါကြောင့် ယနေ့ခေတ်တွင် Deep Learning ကို ပြောင်းလဲအသုံးပြုလာကြပါပြီ။)*

## 🔍 ၂။ SIFT နှင့် ORB (ပုံရိပ်များ၏ လက်ဗွေရာကို ရှာဖွေခြင်း)

**"ဒီပုံ ၂ ပုံက အတူတူပဲလား?"** (သို့မဟုတ်) **"ဒီပုံထဲက အရာဝတ္ထုက နောက်ပုံထဲမှာရော ပါသလား?"** ဆိုတာကို ကွန်ပျူတာက သိဖို့အတွက် Feature Matching နည်းပညာကို သုံးပါတယ်။ ဖုန်းတွေမှာ Panorama ပုံတွေ ဆက်တာ (Image Stitching) ဟာ ဒီနည်းပညာကို သုံးထားတာပါ။

ဒီနေရာမှာ **Keypoints** နဲ့ **Descriptors** ဆိုတာ ပါလာပါတယ်။
*   **Keypoints (အရေးပါသော အမှတ်များ):** ပုံထဲမှာရှိတဲ့ အလွန်ထူးခြားတဲ့ ထောင့်ချိုးတွေ၊ အစွန်းတွေကို Keypoint အဖြစ် သတ်မှတ်ပါတယ်။ (ဒါဟာ ပုံရဲ့ လက်ဗွေရာတွေပါပဲ)။
*   **Descriptors:** အဲ့ဒီ Keypoint လေးရဲ့ ဘေးပတ်လည်မှာ ဘယ်လို အရောင်အသွေး/အနားသတ်တွေ ရှိလဲဆိုတာကို ဂဏန်းတွေနဲ့ မှတ်သားထားတာ ဖြစ်ပါတယ်။

အထင်ရှားဆုံး Algorithm တွေကတော့ **SIFT** (Scale-Invariant Feature Transform) နဲ့ **ORB** (Oriented FAST and Rotated BRIEF) တို့ဖြစ်ပါတယ်။ SIFT က အလွန်တိကျပေမယ့် နှေးပါတယ်။ ORB ကတော့ SIFT ကို အစားထိုးဖို့ ပေါ်လာတဲ့ အလွန်မြန်ဆန်တဲ့ Algorithm တစ်ခု ဖြစ်ပါတယ်။

### 💻 ORB ဖြင့် ပုံ ၂ ပုံ၏ တူညီသော နေရာများကို ချိတ်ဆက်ခြင်း
```python
import cv2

def match_features():
    # ပုံ ၂ ပုံကို Grayscale ဖြင့် ဖတ်ပါ
    img1 = cv2.imread('book_cover.jpg', 0) # ရှာချင်သော မူရင်းစာအုပ်ပုံ
    img2 = cv2.imread('book_in_scene.jpg', 0) # စာအုပ်ပါဝင်သော ပတ်ဝန်းကျင်ပုံ

    # ORB Detector ကို ဖန်တီးခြင်း
    orb = cv2.ORB_create()

    # ပုံ ၂ ပုံလုံးအတွက် Keypoints (kp) နှင့် Descriptors (des) များကို ရှာဖွေခြင်း
    kp1, des1 = orb.detectAndCompute(img1, None)
    kp2, des2 = orb.detectAndCompute(img2, None)

    # Brute-Force Matcher ဖြင့် ပုံ ၂ ပုံမှ Descriptors များကို တိုက်စစ်ခြင်း
    bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
    matches = bf.match(des1, des2)

    # အတူညီဆုံး (Distance အနည်းဆုံး) အမှတ်များကို အစဉ်လိုက်စီခြင်း
    matches = sorted(matches, key=lambda x: x.distance)

    # အတူညီဆုံး ပထမ အမှတ် ၂၀ ကို ဆက်ဆွဲပြခြင်း
    result = cv2.drawMatches(img1, kp1, img2, kp2, matches[:20], None, flags=2)

    cv2.imshow('Feature Matching', result)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

match_features()
```
*(ဒီ Code ကို Run လိုက်ရင် ပုံ ၂ ပုံကြားမှာ တူညီတဲ့ နေရာလေးတွေကို မျဉ်းကြောင်းလေးတွေနဲ့ လှမ်းဆက်ပေးထားတာကို လှပစွာ မြင်တွေ့ရပါလိမ့်မယ်။)*

## 🚀 ၃။ ဘာကြောင့် Deep Learning ကို ကူးပြောင်းလာကြသလဲ? (The Shift to DL)

Haar, SIFT, ORB စတဲ့ Traditional Methods တွေဟာ အလွန်ထက်မြက်ပေမယ့် အားနည်းချက် ကြီးကြီးမားမား တစ်ခုရှိပါတယ်။ အဲ့ဒါကတော့ **"ပြောင်းလွယ်ပြင်လွယ် မရှိခြင်း" (Lack of Generalization)** ပါပဲ။

Haar Cascade နဲ့ မျက်နှာရှာတဲ့အခါ လူက Mask တပ်ထားရင်၊ မျက်မှန်တပ်ထားရင်၊ ဒါမှမဟုတ် ခွေးမျက်နှာတွေကို ရှာချင်ရင် ပုံသေနည်းတွေကို အစကနေ ပြန်ရေးရ၊ ပြန်တွက်ရပါတယ်။ အလွန်လက်ဝင်ပါတယ်။

**Deep Learning (CNNs)** တွေ ပေါ်လာတဲ့အခါမှာတော့ အဲ့ဒီ "Feature Extraction" အပိုင်းကို လူက တွက်ထုတ်ပေးစရာ မလိုတော့ပါဘူး။ 
Neural Network ကြီးထဲကို ပုံတွေ သောင်းနဲ့ချီပြီး ထည့်ပေးလိုက်တာနဲ့...
*   ပထမအလွှာက အနားသတ်မျဉ်း (Edges) တွေကို အလိုလို သင်ယူတယ်။
*   ဒုတိယအလွှာက မျက်လုံး၊ နှာခေါင်း စတဲ့ အစိတ်အပိုင်းတွေကို သင်ယူတယ်။
*   နောက်ဆုံးအလွှာက ဒါဟာ မျက်နှာပဲ ဆိုတာကို **အလိုအလျောက် (Automatically)** ခွဲခြားပေးသွားပါတယ်။ 

ဒါကြောင့် ယနေ့ခေတ် Computer Vision ရဲ့ ၉၀% သော ပြဿနာတွေကို Deep Learning နဲ့ပဲ ဖြေရှင်းကြတော့တာ ဖြစ်ပါတယ်။

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **Feature Extraction** ဆိုသည်မှာ ပုံတစ်ပုံ၏ ထူးခြားသော အမှတ်အသားများကို သင်္ချာနည်းအရ တွက်ထုတ်ခြင်းဖြစ်သည်။
2.  **Haar Cascades** သည် အလင်းအမှောင် ကွာခြားချက်ကို အသုံးပြု၍ မျက်နှာများကို ရှာဖွေပေးသော အစောပိုင်းနည်းပညာ ဖြစ်သည်။
3.  **SIFT / ORB** သည် ပုံများ၏ လက်ဗွေရာ (Keypoints) များကို ရှာဖွေပြီး ပုံ ၂ ပုံ တူ/မတူ (Feature Matching) ပြုလုပ်ရာတွင် အသုံးပြုသည်။
4.  ယနေ့ခေတ်တွင် Feature များကို လူက ကိုယ်တိုင်တွက်ထုတ်ပေးစရာမလိုဘဲ အလိုအလျောက် သင်ယူနိုင်သော **Deep Learning (CNN)** များကို ပြောင်းလဲအသုံးပြုလာကြသည်။
