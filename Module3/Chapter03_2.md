# 📘 Chapter 3.2: Morphological Transformations (ပုံသဏ္ဌာန် ပြုပြင်ပြောင်းလဲခြင်းများ)

Computer Vision မှာ အရောင်ခွဲထုတ်တာပဲဖြစ်ဖြစ်၊ စာရွက်တွေကို Scan ဖတ်တာပဲဖြစ်ဖြစ် လုပ်တဲ့အခါ၊ ထွက်လာတဲ့ အဖြူအမည်း (Binary) ပုံတွေမှာ မလိုလားအပ်တဲ့ အစက်အပြောက်လေးတွေ ပါလာတတ်ပါတယ်။ 

*   တချို့နေရာတွေမှာ အပြင်ဘက် နောက်ခံ (Background) မှာ အဖြူစက်လေးတွေ လွင့်စင်နေတတ်ပါတယ်။
*   တချို့နေရာတွေမှာတော့ ကိုယ်လိုချင်တဲ့ အရာဝတ္ထု (ဥပမာ - စာလုံး) ရဲ့ အတွင်းထဲမှာ အမည်းရောင် အပေါက်လေးတွေ ဖြစ်နေတတ်ပါတယ်။ သို့မဟုတ် စာလုံးတွေ ပြတ်တောက်နေတတ်ပါတယ်။

ဒီလို "ပုံသဏ္ဌာန် (Shape)" ပိုင်းဆိုင်ရာ ချို့ယွင်းချက်တွေကို ပြုပြင်ဖို့အတွက် **Morphological Transformations** တွေကို အသုံးပြုရပါတယ်။ အဓိကအားဖြင့် **Binary Images (အဖြူနှင့်အမည်းသာ ပါသောပုံများ)** ပေါ်မှာ အသုံးပြုလေ့ရှိပါတယ်။

---

## 🛠️ Structuring Element (Kernel) ဆိုတာ ဘာလဲ?

Morphological Operation တွေ လုပ်ဖို့အတွက် အရင်အခန်းက Blur လုပ်သလိုမျိုးပဲ **Kernel** (Numpy Array လေးတစ်ခု) လိုအပ်ပါတယ်။ များသောအားဖြင့် `3x3` သို့မဟုတ် `5x5` အပြည့် (1 တွေချည်းပဲ ပါတဲ့) Matrix ကို အသုံးပြုလေ့ရှိပါတယ်။

```python
import cv2
import numpy as np

# 5x5 အရွယ်အစားရှိသော Kernel တစ်ခု ဖန်တီးခြင်း
kernel = np.ones((5, 5), np.uint8)
```

---

## ➖ ၁။ Erosion (အနားသတ်များကို စားပစ်ခြင်း / ပါးသွားစေခြင်း)

Erosion ရဲ့ သဘောတရားက မြေဆီလွှာ ရေစားသလိုမျိုးပါပဲ။ ပုံထဲမှာရှိတဲ့ အဖြူရောင် အရာဝတ္ထုတွေရဲ့ အနားသတ်တွေကို စားပစ်လိုက် (ပါးသွားအောင် လုပ်လိုက်) တာ ဖြစ်ပါတယ်။

**အလုပ်လုပ်ပုံ:** Kernel လေးက ပုံပေါ်မှာ ရွေ့သွားတဲ့အခါ၊ သူ့အောက်မှာရှိတဲ့ Pixel တွေ **အားလုံး** အဖြူရောင် (1) ဖြစ်မှသာ အလယ်ဗဟိုကို အဖြူရောင်အဖြစ် ထားပါတယ်။ တစ်ကွက်လေး အမည်းရောင် (0) ဖြစ်နေရင်တောင် အားလုံးကို အမည်းရောင် ပြောင်းပစ်လိုက်ပါတယ်။

**အသုံးဝင်ပုံ:** နောက်ခံမှာ လွင့်စင်နေတဲ့ အဖြူစက် (Noise) အသေးလေးတွေကို ဖျောက်ပစ်ဖို့နဲ့၊ တစ်ခုနဲ့တစ်ခု ကပ်နေတဲ့ အရာဝတ္ထုတွေကို ခွဲထုတ်ဖို့ အသုံးပြုပါတယ်။

```python
# iterations = 1 ဆိုသည်မှာ 1 ကြိမ် စားပစ်မည်ဟု ဆိုလိုသည်
erosion = cv2.erode(image, kernel, iterations=1)
```

---

## ➕ ၂။ Dilation (အနားသတ်များကို ချဲ့ကားခြင်း / ထူလာစေခြင်း)

Dilation ကတော့ Erosion ရဲ့ ပြောင်းပြန်ဖြစ်ပါတယ်။ အဖြူရောင် အရာဝတ္ထုတွေကို ပိုပြီး ထူလာအောင်၊ ကြီးလာအောင် ချဲ့ကားပေးတာ ဖြစ်ပါတယ်။

**အလုပ်လုပ်ပုံ:** Kernel အောက်မှာရှိတဲ့ Pixel တွေထဲက **တစ်ခုခု** အဖြူရောင် (1) ဖြစ်နေတာနဲ့ အလယ်ဗဟိုကို အဖြူရောင်အဖြစ် ပြောင်းပစ်လိုက်ပါတယ်။ 

**အသုံးဝင်ပုံ:** Erosion လုပ်လိုက်လို့ ပါးသွားတဲ့ အရာဝတ္ထုတွေကို မူလအရွယ်အစား ပြန်ဖြစ်အောင် ချဲ့တာ၊ ပြတ်တောက်နေတဲ့ စာလုံး/မျဉ်းကြောင်းတွေကို ပြန်ဆက်ပေးတာ တွေမှာ အသုံးပြုပါတယ်။

```python
dilation = cv2.dilate(image, kernel, iterations=1)
```

---

## 🧹 ၃။ Opening (အပြင်ဘက်မှ Noise များ ဖယ်ရှားခြင်း)

Opening ဆိုတာ **Erosion ကို အရင်လုပ်ပြီး၊ ပြီးမှ Dilation ကို ဆက်လုပ်တာ** ဖြစ်ပါတယ်။

**ဘာကြောင့်သုံးတာလဲ?**
Erosion လုပ်လိုက်ရင် နောက်ခံက အဖြူစက်လေးတွေ (Noise) ပျောက်သွားပါတယ်။ ဒါပေမယ့် ကိုယ်လိုချင်တဲ့ အရာဝတ္ထုကြီးလည်း ပါးသွားပါတယ်။ ဒါကြောင့် ပါးသွားတဲ့ အရာဝတ္ထုကြီး မူလအရွယ် ပြန်ဖြစ်အောင် Dilation နဲ့ ပြန်ချဲ့လိုက်တာပါ။ (အစက်အသေးလေးတွေက Erosion အဆင့်မှာတင် လုံးဝပျောက်သွားပြီ ဖြစ်တဲ့အတွက် Dilation လုပ်တဲ့အခါ ပြန်ပါမလာတော့ပါဘူး)။

```python
# cv2.MORPH_OPEN ကို အသုံးပြုသည်
opening = cv2.morphologyEx(image, cv2.MORPH_OPEN, kernel)
```

---

## 🕳️ ၄။ Closing (အတွင်းပိုင်းရှိ အပေါက်ငယ်များ ဖာထေးခြင်း)

Closing ကတော့ Opening ရဲ့ ပြောင်းပြန်ပါ။ **Dilation ကို အရင်လုပ်ပြီး၊ ပြီးမှ Erosion ကို ဆက်လုပ်တာ** ဖြစ်ပါတယ်။

**ဘာကြောင့်သုံးတာလဲ?**
ကိုယ်လိုချင်တဲ့ အဖြူရောင် အရာဝတ္ထုကြီးရဲ့ အတွင်းထဲမှာ အမည်းစက်/အပေါက်လေးတွေ ဖြစ်နေတဲ့အခါ အသုံးပြုပါတယ်။ Dilation အရင်လုပ်လိုက်တဲ့အတွက် အဲ့ဒီ အပေါက်လေးတွေ ပိတ်သွား (ဖာထေးပြီးသား ဖြစ်သွား) ပါတယ်။ ပြီးမှ ကြီးသွားတဲ့ အရာဝတ္ထုကို Erosion နဲ့ မူလအရွယ် ပြန်ရောက်အောင် ပြန်စားပစ်လိုက်တာ ဖြစ်ပါတယ်။

```python
# cv2.MORPH_CLOSE ကို အသုံးပြုသည်
closing = cv2.morphologyEx(image, cv2.MORPH_CLOSE, kernel)
```

## 🧩 ၅။ အစအဆုံး နှိုင်းယှဉ်ပြသခြင်း (Complete Example)

ဒီ Operations တွေရဲ့ အလုပ်လုပ်ပုံကို ပိုမိုမြင်သာစေဖို့ Code တစ်ခုတည်းမှာ ပေါင်းရေးပြီး စမ်းသပ်ကြည့်ကြပါမယ်။ *(ဒီ Code ကို စမ်းသပ်ဖို့ အဖြူအမည်း (B&W) စာလုံးတွေပါတဲ့ ပုံတစ်ပုံကို သုံးရင် ပိုကောင်းပါတယ်။)*

```python
import cv2
import numpy as np

def main():
    # အဖြူအမည်းပုံ (Grayscale) ဖြင့် ဖတ်ပါ
    image = cv2.imread('j_noise.png', 0) 
    
    if image is None:
        print("Image not found! Please check the path.")
        return

    # 5x5 Kernel ဖန်တီးခြင်း
    kernel = np.ones((5, 5), np.uint8)

    # 1. Erosion (ပါးသွားစေမည် / အစက်များ ပျောက်မည်)
    erosion = cv2.erode(image, kernel, iterations=1)

    # 2. Dilation (ထူလာစေမည် / ပြတ်နေသည်များ ဆက်သွားမည်)
    dilation = cv2.dilate(image, kernel, iterations=1)

    # 3. Opening (Erosion -> Dilation) 
    # Background မှ အဖြူစက်များ ဖယ်ရှားရန် အကောင်းဆုံး
    opening = cv2.morphologyEx(image, cv2.MORPH_OPEN, kernel)

    # 4. Closing (Dilation -> Erosion) 
    # Object အတွင်းမှ အမည်းပေါက်များ ဖာထေးရန် အကောင်းဆုံး
    closing = cv2.morphologyEx(image, cv2.MORPH_CLOSE, kernel)

    # ရလဒ်များ ပြသခြင်း
    cv2.imshow('1. Original', image)
    cv2.imshow('2. Erosion', erosion)
    cv2.imshow('3. Dilation', dilation)
    cv2.imshow('4. Opening', opening)
    cv2.imshow('5. Closing', closing)

    cv2.waitKey(0)
    cv2.destroyAllWindows()

if __name__ == "__main__":
    main()
```

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **Morphological Operations** များကို အဖြူအမည်း (Binary) ပုံများ၏ ပုံသဏ္ဌာန် ချို့ယွင်းချက်များကို ပြုပြင်ရန် အသုံးပြုသည်။
2.  **Erosion (`cv2.erode`)** သည် အဖြူရောင်များကို ပါးသွားစေပြီး၊ အစက်အပြောက်ငယ်များကို ဖယ်ရှားပေးသည်။
3.  **Dilation (`cv2.dilate`)** သည် အဖြူရောင်များကို ထူလာစေပြီး၊ ပြတ်တောက်နေသော အစိတ်အပိုင်းများကို ပြန်ဆက်ပေးသည်။
4.  **Opening (`cv2.MORPH_OPEN`)** သည် နောက်ခံ (Background) တွင် လွင့်စင်နေသော Noise များကို ဖယ်ရှားရန် အကောင်းဆုံးဖြစ်သည်။
5.  **Closing (`cv2.MORPH_CLOSE`)** သည် အရာဝတ္ထု (Foreground) အတွင်းရှိ အပေါက်ငယ်လေးများကို ဖာထေးရန် အကောင်းဆုံးဖြစ်သည်။
