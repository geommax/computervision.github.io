# 📘 Chapter 8.2: Vision Transformer (ViT) Architecture (ViT ၏ ဖွဲ့စည်းပုံနှင့် ပုံရိပ်များကို ပိုင်းဖြတ်ခြင်း)

Transformer တွေဟာ မူလက NLP (စာသား) တွေအတွက် ဖန်တီးထားတာပါ။
ဥပမာ - *"I love Artificial Intelligence"* ဆိုတဲ့ စာကြောင်းကို Transformer ထဲထည့်ရင်၊ စာလုံး (Words) ၄ လုံး (သို့မဟုတ် Tokens ၄ ခု) အနေနဲ့ ခွဲပြီး အလွယ်တကူ ထည့်သွင်းတွက်ချက်လို့ ရပါတယ်။

**ဒါပေမယ့် Computer Vision မှာ ပြဿနာရှိပါတယ်။**
`1920 x 1080` ကာလာပုံတစ်ပုံမှာ Pixel အရေအတွက် **၆ သန်းကျော်** (1920x1080x3) ရှိပါတယ်။ Pixel တစ်ခုချင်းစီကို စာလုံးတစ်လုံး (Token) အဖြစ် သတ်မှတ်ပြီး Transformer ထဲ ထည့်သွင်းတွက်ချက်မယ်ဆိုရင် ယနေ့ခေတ် ကမ္ဘာ့အမြန်ဆုံး Supercomputer ကြီးတွေတောင် Memory မလောက်ဘဲ ပျက်ကျသွားပါလိမ့်မယ်။ (Attention က တွက်ချက်ရတာ အလွန်လေးလံလို့ပါ)။

ဒီပြဿနာကို ၂၀၂၀ ခုနှစ်မှာ Google က သုတေသီတွေ ဖြေရှင်းခဲ့တဲ့ နည်းလမ်းကတော့ **"An Image is Worth 16x16 Words (ပုံတစ်ပုံဟာ စာလုံးအရွယ်အစား 16x16 တွေနဲ့ ဖွဲ့စည်းထားတယ်)"** ဆိုတဲ့ အယူအဆပဲ ဖြစ်ပါတယ်။

---

## 🧩 ၁။ Image Patches (ပုံကို ဂျစ်ဆောပက်ဇယ်များအဖြစ် ပိုင်းဖြတ်ခြင်း)

Pixel သန်းချီကို Transformer ထဲ တိုက်ရိုက်မထည့်တော့ဘဲ၊ ပုံတစ်ပုံလုံးကို **Patches (လေးထောင့်ကွက်ငယ်လေးများ)** အဖြစ် ပိုင်းဖြတ်လိုက်ပါတယ်။

*   အများအားဖြင့် `16x16` အရွယ်အစားရှိတဲ့ Patch လေးတွေအဖြစ် ပိုင်းဖြတ်ပါတယ်။
*   ဥပမာ - `224x224` အရွယ်အစားရှိတဲ့ ပုံတစ်ပုံကို `16x16` Patches တွေခွဲလိုက်ရင် (224/16) x (224/16) = **၁၉၆ ကွက်** ရရှိပါတယ်။
*   **The Magic:** အခုဆိုရင် Pixel ပေါင်း သိန်းချီရှိတဲ့ ပုံကြီးဟာ၊ **"Tokens အရေအတွက် ၁၉၆ ခု (စာလုံးရေ ၁၉၆ လုံး ပါဝင်သော စာပိုဒ်တစ်ခု)"** အဖြစ်သို့ ပြောင်းလဲသွားပါပြီ။ ဒီအရေအတွက်ဟာ Transformer တွေအတွက် အလွယ်တကူ တွက်ချက်နိုင်တဲ့ ပမာဏ ဖြစ်သွားပါတယ်။

---

## 📏 ၂။ Linear Projection / Flattening (ပြားချပ်စေခြင်း)

ပိုင်းဖြတ်လိုက်တဲ့ 16x16 Patch (2D ဇယားကွက်) လေးတစ်ခုချင်းစီကို၊ AI က နားလည်တဲ့ 1D Vector (မျဉ်းဖြောင့် ဂဏန်းတန်းကြီး) ဖြစ်အောင် ဆွဲဆန့်လိုက်ပါတယ်။ ဒါကို Linear Projection လုပ်တယ်လို့ ခေါ်ပါတယ်။

ဒီအဆင့်ပြီးသွားရင် ပုံတစ်ပုံဟာ `[196, 768]` လိုမျိုး အရွယ်အစားရှိတဲ့ Matrix ကြီးဖြစ်သွားပါတယ်။ (196 ဆိုတာက Patch အရေအတွက်ဖြစ်ပြီး၊ 768 ဆိုတာက Patch တစ်ခုချင်းစီကို ကိုယ်စားပြုတဲ့ ဂဏန်းအရေအတွက် ဖြစ်ပါတယ်)။

---

## 📍 ၃။ Positional Embeddings (နေရာအမှတ်အသား တပ်ပေးခြင်း)

Transformer တွေရဲ့ အကြီးမားဆုံး ထူးခြားချက်က **"အစီအစဉ်ကို နားမလည်တာပါပဲ" (No notion of order)**။
ပုံကို Jigsaw Puzzle အတုံး ၁၉၆ တုံး ဖျက်ပြီး AI ဆီ ပေးလိုက်တဲ့အခါ၊ AI က ဘယ်အတုံးက မျက်လုံးလဲ၊ ဘယ်အတုံးက ခြေထောက်လဲ ဆိုတာကို ဆက်စပ်ပြီး (Attention နဲ့) သိနိုင်ပေမယ့်၊ **အဲ့ဒီမျက်လုံးက ဘယ်ဘက်အပေါ်ထောင့်မှာ ရှိတာလား၊ ညာဘက်အောက်ထောင့်မှာ ရှိတာလား (Spatial Location)** ဆိုတာကို လုံးဝ မသိပါဘူး။

ဒါကြောင့် ပုံကို ပြန်ဆက်လို့ရအောင် Patch တစ်ခုချင်းစီရဲ့ အချက်အလက်ထဲကို **Positional Embeddings (နေရာပြ ဂဏန်းများ)** ကို မဖြစ်မနေ ထပ်ပေါင်းထည့်ပေးရပါတယ်။
*   *ဥပမာ: "ငါက Patch ပါ" ဆိုတာထက် "ငါက (Row 1, Column 1) ကလာတဲ့ Patch ပါ" ဆိုပြီး ကပ်ပေးလိုက်တာ ဖြစ်ပါတယ်။*

---

## 👑 ၄။ The CLS Token (ခေါင်းဆောင် သင်္ကေတ)

Patches ၁၉၆ ခုလုံးကို Positional Embeddings တွေတပ်ပြီးရင် Transformer ရဲ့ ဉီးနှောက် (Encoder) ထဲကို ထည့်ဖို့ အဆင်သင့် ဖြစ်နေပါပြီ။ ဒါပေမယ့် နောက်ဆုံးမှာ ဒီပုံက ခွေးလား၊ ကြောင်လား ဆုံးဖြတ်ချက်ပေးဖို့ **"ပုံတစ်ပုံလုံးရဲ့ အချက်အလက်တွေကို စုစည်းပေးမယ့် ခေါင်းဆောင်"** လိုအပ်ပါတယ်။

ဒါကြောင့် `[CLS]` (Classification Token) လို့ခေါ်တဲ့ အတုအယောင် Patch အသစ်တစ်ခုကို အရှေ့ဆုံးမှာ ထပ်ပေါင်းထည့်လိုက်ပါတယ်။
စုစုပေါင်း (၁၉၆ + ၁ = ၁၉၇) ခုသော Tokens တွေကို Transformer ထဲ ထည့်လိုက်ပါတယ်။

Transformer ရဲ့ Attention တွေ တွက်ချက်ပြီးတဲ့အခါ... တခြား Patch ၁၉၆ ခုကို လွှင့်ပစ်လိုက်ပြီး၊ အဲ့ဒီ **`[CLS]` Token တစ်ခုတည်းကနေ ထွက်လာတဲ့ အဖြေကိုပဲ ယူပြီး "ဒါဟာ ခွေးပါ" လို့ ဆုံးဖြတ်ချက် (Classification) ချလိုက်တာ ဖြစ်ပါတယ်။**

![Vision Transformer Architecture](https://via.placeholder.com/800x400?text=Image+-%3E+16x16+Patches+-%3E+Flatten+%2B+Position+Embeddings+-%3E+Transformer+Encoder+-%3E+Output)
*(မှတ်ချက် - ဤနေရာတွင် ViT ၏ မူရင်း Paper မှ Image -> Patches -> Linear Projection -> Transformer Encoder ပုံကို ထည့်သွင်းရန်)*

## 💻 ၅။ PyTorch ဖြင့် Patches ဖြတ်ပုံကို မြင်သာအောင် ကြည့်ခြင်း

Computer Vision သမားတွေဟာ ပုံကို Patches ခွဲဖို့အတွက် PyTorch ရဲ့ Unfold သို့မဟုတ် အလွန်လွယ်ကူတဲ့ `einops` library ကို အသုံးပြုလေ့ရှိပါတယ်။

```python
import torch
# einops သည် Tensor များ၏ dimension များကို အလွယ်တကူ ပြောင်းလဲပေးနိုင်သော နာမည်ကြီး Library ဖြစ်သည်
from einops import rearrange 

def create_patches():
    # ဥပမာ - 1 image, 3 channels, 224x224 height x width (Batch, C, H, W)
    image = torch.randn(1, 3, 224, 224)
    print(f"Original Image Shape: {image.shape}")

    patch_size = 16
    
    # Einops ဖြင့် 224x224 ပုံကို 16x16 patches များအဖြစ် ဖြတ်ခြင်း
    # h = (224/16 = 14), w = (224/16 = 14)
    # p1 = 16, p2 = 16
    patches = rearrange(image, 'b c (h p1) (w p2) -> b (h w) (p1 p2 c)', p1=patch_size, p2=patch_size)

    # Output ကို ကြည့်ကြပါစို့
    print(f"Patches Shape: {patches.shape}")
    # ရလဒ်: [1, 196, 768]
    # ဆိုလိုသည်မှာ -[Batch, Patches အရေအတွက်(14x14=196), Patch တစ်ခုစီ၏အချက်အလက်(16x16x3=768)]
    print("Success: ပုံတစ်ပုံကို Tokens (Words) ၁၉၆ ခုပါသော စာကြောင်းတစ်ကြောင်းအဖြစ် ပြောင်းလဲပြီးပါပြီ!")

if __name__ == "__main__":
    create_patches()
```

## 📝 အနှစ်ချုပ် (Key Takeaways)
1. **ViT (Vision Transformer)** သည် ပုံရိပ်များကို `16x16` အရွယ်အစားရှိ **Patches (အပိုင်းငယ်လေးများ)** အဖြစ် ပိုင်းဖြတ်ပြီး Transformer အတွင်းသို့ စာသား (Words) များကဲ့သို့ ထည့်သွင်းသည်။
2. ပုံများကို ပိုင်းဖြတ်ပြီး Flatten (ဆွဲဆန့်) လိုက်သော လုပ်ငန်းစဉ်ကို **Linear Projection** ဟု ခေါ်သည်။
3. Transformer သည် အစီအစဉ်ကို နားမလည်သောကြောင့် Patch တစ်ခုချင်းစီ၏ နေရာကို သိစေရန် **Positional Embeddings** များ ပေါင်းထည့်ပေးရသည်။
4. ပုံတစ်ပုံလုံး၏ အချက်အလက်များကို ခြုံငုံသုံးသပ်၍ နောက်ဆုံး Classification အဖြေကို ထုတ်ပေးရန် အရှေ့ဆုံးတွင် **`[CLS]` Token** ကို အသုံးပြုသည်။
