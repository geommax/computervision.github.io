# 📘 Chapter 5.2: Pooling Layers, Flattening & Fully Connected Layers (အချက်အလက်များ လျှော့ချခြင်းနှင့် နောက်ဆုံးဆုံးဖြတ်ချက်ချခြင်း)

အရင်အခန်း (Chapter 5.1) မှာ Convolutional Layer (Conv2d) တွေက ပုံတွေထဲကနေ အရေးကြီးတဲ့ Feature (အနားသတ်မျဉ်းတွေ၊ ပုံသဏ္ဌာန်တွေ) ကို လိုက်ရှာတယ်ဆိုတာ သိခဲ့ရပါတယ်။ 

ဒါပေမယ့် ပုံတစ်ပုံကို Filter ၆၄ ခုလောက်ပတ်ပြီး ရှာလိုက်တဲ့အခါ ထွက်လာတဲ့ Data ပမာဏဟာ အလွန်ကြီးမားသွားပါတယ်။ ဒီ Data ကြီးတစ်ခုလုံးကို နောက်တစ်ဆင့်တွေဆီ ဆက်ပို့ရင် ကွန်ပျူတာ Memory မလောက်တဲ့အပြင်၊ တွက်ချက်ရတာလည်း အလွန်နှေးကွေးသွားပါမယ်။ ဒါကြောင့် **အရေးကြီးတဲ့ အချက်အလက်တွေကို ချန်ထားခဲ့ပြီး၊ မလိုအပ်တဲ့ အချက်အလက်တွေကို လျှော့ချပစ်မယ့် "Pooling"** ဆိုတဲ့ နည်းပညာကို အသုံးပြုရပါတယ်။

---

## 📉 ၁။ Pooling Layer ဆိုတာ ဘာလဲ? (Dimensionality Reduction)

Pooling ဆိုတာ ပုံရဲ့ (အလျား x အနံ) အရွယ်အစားကို သေးငယ်သွားအောင် (Downsampling) လုပ်ပစ်တာ ဖြစ်ပါတယ်။ အဓိက အားဖြင့် `2x2` အရွယ်အစားရှိတဲ့ Window လေးနဲ့ ပုံပေါ်မှာ ရွေ့လျားပြီး Data တွေကို လျှော့ချပါတယ်။

အသုံးအများဆုံး Pooling အမျိုးအစား ၂ ခု ရှိပါတယ်။

### (A) Max Pooling (အသုံးအများဆုံး)
*   **အလုပ်လုပ်ပုံ:** `2x2` ဇယားကွက်လေး (Pixel ၄ ကွက်) ထဲကနေ **အကြီးဆုံး ဂဏန်း (Maximum Value) တစ်ခုတည်းကိုသာ ရွေးချယ်** ပြီး ကျန်တဲ့ ၃ ခုကို လွှင့်ပစ်လိုက်ပါတယ်။
*   **ဘာကြောင့် Max ကို ယူတာလဲ?:** CNN မှာ ဂဏန်းတန်ဖိုး အကြီးဆုံးဆိုတာ **"ဒီနေရာမှာ အနားသတ်မျဉ်း (Feature) အထင်ရှားဆုံး ရှိနေတယ်"** လို့ အဓိပ္ပာယ်ရပါတယ်။ ဒါကြောင့် အရေးအကြီးဆုံး အချက်အလက်ကိုပဲ ဆွဲထုတ်လိုက်တာ ဖြစ်ပါတယ်။

### (B) Average Pooling
*   **အလုပ်လုပ်ပုံ:** `2x2` ဇယားကွက်ထဲက Pixel ၄ ခုလုံးကို ပေါင်းပြီး ပျမ်းမျှ (Average) တန်ဖိုးကို ယူပါတယ်။ 
*   **အားနည်းချက်:** အရေးကြီးတဲ့ Feature တွေဟာ ပျမ်းမျှယူလိုက်တဲ့အခါ အားနည်းသွားတတ်တဲ့အတွက် ကြားအလွှာတွေမှာ သိပ်မသုံးကြပါဘူး။

> 💡 **Max Pooling ၏ စွမ်းရည် (Translation Invariance):**
> ပုံထဲမှာ ကြောင်လေးက ဘယ်ဘက်ကို နည်းနည်းရွေ့သွားရင်ဖြစ်ဖြစ်၊ ညာဘက်ကို နည်းနည်းစောင်းသွားရင်ဖြစ်ဖြစ် Max Pooling က အကြီးဆုံးဂဏန်းကိုပဲ ယူတာဖြစ်တဲ့အတွက်၊ AI က **"ကြောင်ဘယ်နေရာရောက်ရောက် ကြောင်မှန်း သိနိုင်စွမ်း"** ကို ပိုမို တိုးတက်စေပါတယ်။

*PyTorch တွင် ရေးသားပုံ:* `nn.MaxPool2d(kernel_size=2, stride=2)` 
*(ဤသို့ရေးပါက ပုံ၏အရွယ်အစားသည် တစ်ဝက်တိတိ (ဥပမာ- 32x32 မှ 16x16 သို့) သေးငယ်သွားမည် ဖြစ်သည်။)*

## 🗜️ ၂။ Flattening (ပြားချပ်သွားအောင် ဆွဲဆန့်ခြင်း)

Conv2d နဲ့ MaxPool2d တွေကို အလွှာများစွာ ဖြတ်သန်းပြီးတဲ့အခါ နောက်ဆုံးမှာ `(Channels, Height, Width)` ဆိုတဲ့ 3D Tensor တုံးကြီး ကျန်ခဲ့ပါတယ်။ (ဥပမာ - `64 x 7 x 7`)။

ဒါပေမယ့် နောက်ဆုံး ဆုံးဖြတ်ချက်ချမယ့် Artificial Neural Network (ANN) လေးတွေဟာ 3D တုံးကြီးတွေကို လက်မခံနိုင်ပါဘူး။ သူတို့က `1D Array` မျဉ်းဖြောင့်ကြီးတွေကိုပဲ လက်ခံနိုင်ပါတယ်။

ဒါကြောင့် အဲ့ဒီ 3D တုံးကြီးကို **ရှေ့ကနေ နောက်သို့ တစ်တန်းတည်းဖြစ်အောင် ဖြန့်ချလိုက်တာကို Flattening** လို့ ခေါ်ပါတယ်။
*   ဥပမာ - `64 Channels x 7 Height x 7 Width = 3136` ဖြစ်တဲ့အတွက်၊ ဂဏန်းပေါင်း ၃၁၃၆ လုံးပါတဲ့ 1D Vector (မျဉ်းဖြောင့်) ကြီး အဖြစ် ပြောင်းလဲသွားပါတယ်။

*PyTorch တွင် ရေးသားပုံ:* `nn.Flatten()`

---

## 🧠 ၃။ Fully Connected (FC) Layers (နောက်ဆုံး ဆုံးဖြတ်ချက်ချခြင်း)

Flatten လုပ်ပြီး ထွက်လာတဲ့ 1D ဂဏန်းတွေဟာ ဘာတွေလဲ? 
အဲ့ဒါတွေက အစောပိုင်းမှာ CNN က ရှာဖွေထားတဲ့ Feature တွေ (ဥပမာ - ဘီးပါသလား၊ မှန်ပါသလား၊ တံခါးပါသလား ကို ကိုယ်စားပြုတဲ့ ဂဏန်းတွေ) ပဲ ဖြစ်ပါတယ်။

**Fully Connected Layer (PyTorch တွင် `nn.Linear` ဟုခေါ်သည်)** ဟာ အဲ့ဒီ Feature တွေ အားလုံးကို ခြုံငုံသုံးသပ်ပြီး ဆုံးဖြတ်ချက် ချပေးမယ့် **"ဦးနှောက်"** ပါပဲ။

*   **အလုပ်လုပ်ပုံ:** သူက "ဘီး ၂ ဘီး တွေ့တယ်၊ အင်ဂျင် တွေ့တယ် -> ဒါဆိုရင် ဆိုင်ကယ် ဖြစ်ဖို့ ၉၀% သေချာတယ်" လို့ ယုတ္တိကျကျ ဆုံးဖြတ်ပေးပါတယ်။
*   နောက်ဆုံး Output မှာ မိမိ ခွဲခြားချင်တဲ့ အရေအတွက် (Classes) အတိုင်း ထွက်အောင် ဖန်တီးရပါတယ်။ (ဥပမာ - ခွေး နဲ့ ကြောင် ၂ မျိုးတည်းခွဲမှာဆိုရင် Output=2)။
*   ပြီးရင် Chapter 4.2 က **Softmax** ကို သုံးပြီး ရာခိုင်နှုန်း (Probability) အဖြစ် ပြောင်းလဲလိုက်ပါတယ်။

## 💻 ၄။ အစအဆုံး ပေါင်းရေးကြည့်ခြင်း (A Complete CNN Architecture in PyTorch)

အခုသင်ခဲ့သမျှ (Conv2d, ReLU, MaxPool, Flatten, Linear) အားလုံးကို ပေါင်းပြီး PyTorch နဲ့ ပြီးပြည့်စုံတဲ့ အခြေခံ CNN Model လေးတစ်ခု တည်ဆောက်ကြည့်ကြပါမယ်။

```python
import torch
import torch.nn as nn

# Model ကို Object-Oriented Programming (OOP) Class အနေဖြင့် တည်ဆောက်ခြင်း
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(SimpleCNN, self).__init__()
        
        # အပိုင်း (၁): Feature Extraction (CNN + ReLU + MaxPool)
        self.features = nn.Sequential(
            # Input: [Batch, 3, 32, 32] (ဥပမာ - 32x32 ကာလာပုံ)
            nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2) 
            # MaxPool ကြောင့်[Batch, 16, 16, 16] သို့ သေးငယ်သွားမည်
        )
        
        # အပိုင်း (၂): Flattening (3D မှ 1D သို့ ပြောင်းခြင်း)
        self.flatten = nn.Flatten()
        # Flatten ကြောင့် 16*16*16 = 4096 လုံးပါသော 1D Vector ရရှိမည်
        
        # အပိုင်း (၃): Classification (Fully Connected Layer)
        self.classifier = nn.Sequential(
            nn.Linear(in_features=4096, out_features=128),
            nn.ReLU(),
            nn.Linear(in_features=128, out_features=num_classes) 
            # နောက်ဆုံးတွင် Class အရေအတွက် (ဥပမာ - 10 မျိုး) သို့ ပြောင်းပေးသည်
        )

    def forward(self, x):
        x = self.features(x)     # CNN ဖြင့် Feature ရှာမည်
        x = self.flatten(x)      # 1D ပြောင်းမည်
        x = self.classifier(x)   # Linear ဖြင့် ဆုံးဖြတ်ချက်ချမည်
        return x

# Model ကို ခေါ်ယူတည်ဆောက်ခြင်း (Class 10 မျိုး ခွဲမည်)
model = SimpleCNN(num_classes=10)
print(model)

# ဥပမာ - ပုံတစ်ပုံ (Batch=1, C=3, H=32, W=32) ဝင်လာသည်ဟု သဘောထားပြီး စမ်းသပ်ကြည့်ခြင်း
dummy_image = torch.randn(1, 3, 32, 32)
output = model(dummy_image)

print(f"\nOutput Shape: {output.shape}") 
# Output: torch.Size([1, 10]) -> Class ၁၀ မျိုးအတွက် ရမှတ် ၁၀ ခု ထွက်လာပါသည်!
```

*(ရှင်းလင်းချက် - PyTorch တွင် Model ကို အမြဲတမ်း `nn.Module` မှ ဆင်းသက်၍ (Inherit လုပ်၍) ရေးသားရပြီး၊ အလွှာများကို `__init__` တွင် ကြိုတင်သတ်မှတ်ကာ၊ အလုပ်လုပ်မည့် အစီအစဉ်ကို `forward` function ထဲတွင် ရေးသားရပါသည်။)*

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **Max Pooling (`nn.MaxPool2d`)** သည် ပုံအရွယ်အစားကို (များသောအားဖြင့် တစ်ဝက်) လျှော့ချပေးပြီး၊ အရေးအကြီးဆုံး Feature များကိုသာ ရွေးချယ်ချန်လှပ်ထားခဲ့သည်။ ကွန်ပျူတာ Memory ကို များစွာ သက်သာစေသည်။
2.  **Flattening (`nn.Flatten`)** သည် CNN မှ ထွက်လာသော 3D Feature Map များကို Fully Connected Layer များ နားလည်စေရန် 1D Array အဖြစ် ဆွဲဆန့်ပေးသော ပေါင်းကူးတံတား ဖြစ်သည်။
3.  **Fully Connected Layers (`nn.Linear`)** သည် ရှာဖွေတွေ့ရှိထားသော Feature များကို အခြေခံ၍ နောက်ဆုံး "ခွေးလား၊ ကြောင်လား" ဆုံးဖြတ်ချက် (Classification) ချပေးသော အစိတ်အပိုင်း ဖြစ်သည်။
