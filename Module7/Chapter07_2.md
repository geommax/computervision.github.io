# 📘 Chapter 7.2: Medical & Binary Segmentation (ဆေးဘက်ဆိုင်ရာ ပုံရိပ်ပိုင်းခြားခြင်းနှင့် U-Net)

အရင်အခန်းမှာ Segmentation ရဲ့ အခြေခံ သဘောတရားတွေကို လေ့လာခဲ့ပါတယ်။ လက်တွေ့လုပ်ငန်းခွင်မှာ Segmentation ကို အများဆုံးနဲ့ အရေးတကြီး အသုံးပြုရတဲ့ နယ်ပယ်ကတော့ **ဆေးဘက်ဆိုင်ရာ ပုံရိပ်ခွဲခြမ်းစိတ်ဖြာခြင်း (Medical Image Analysis)** ပဲ ဖြစ်ပါတယ်။

ဥပမာ - MRI Scan သို့မဟုတ် X-Ray ပုံတစ်ပုံထဲကနေ ကင်ဆာအကျိတ် (Tumor) ကို ရှာချင်တယ်ဆိုပါစို့။ ဆရာဝန်တွေဟာ အကျိတ် ဘယ်နားမှာရှိလဲဆိုတာလောက်နဲ့ မလုံလောက်ပါဘူး။ အကျိတ်ရဲ့ ပုံသဏ္ဌာန်က ဘယ်လိုရှိလဲ၊ ဧရိယာ ဘယ်လောက် ကြီးလာလဲ ဆိုတာကိုပါ Pixel တစ်ကွက်ချင်းစီ အတိအကျ သိဖို့ လိုအပ်ပါတယ်။ ဒါကို **Binary Segmentation (အကျိတ် ဟုတ်တယ်(1)၊ မဟုတ်ဘူး(0) နှစ်မျိုးတည်းခွဲခြင်း)** လို့ ခေါ်ပါတယ်။

ဒီလို တိကျတဲ့ တာဝန်တွေအတွက် ၂၀၁၅ ခုနှစ်မှာ ဂျာမနီက သုတေသီတွေ တီထွင်ခဲ့တဲ့ ကမ္ဘာကျော် **U-Net Architecture** ကို အသုံးပြုပါတယ်။

## 🧲 ၁။ U-Net ဆိုတာ ဘာလဲ? ဘာကြောင့် "U" လို့ ခေါ်တာလဲ?

U-Net ဆိုတာ Image Segmentation အတွက် အထူးဖန်တီးထားတဲ့ CNN မော်ဒယ် တစ်မျိုးဖြစ်ပါတယ်။ သူ့ရဲ့ Neural Network အလွှာတွေ စီစဉ်ထားပုံ (Architecture) ကို ပုံဆွဲကြည့်လိုက်တဲ့အခါ အင်္ဂလိပ်အက္ခရာ **"U" ပုံသဏ္ဌာန်** ထွက်လာတဲ့အတွက် U-Net လို့ အမည်ပေးခဲ့တာ ဖြစ်ပါတယ်။

သူ့မှာ အဓိက အစိတ်အပိုင်း ၃ ခု ပါဝင်ပါတယ်။

### (A) Encoder (ဘယ်ဘက်အခြမ်း - ကျုံ့ဝင်ခြင်း)
*   **လုပ်ဆောင်ချက်:** သာမန် CNN (ဥပမာ ResNet) တွေလိုပဲ Convolution နဲ့ Max Pooling တွေကို အကြိမ်ကြိမ်သုံးပြီး ပုံကို သေးငယ်သွားအောင် (Downsampling) လုပ်ပါတယ်။
*   **ရည်ရွယ်ချက်:** ပုံထဲမှာ **"ဘာအရာဝတ္ထု (What)"** ပါလဲဆိုတဲ့ Feature တွေကို ရှာဖွေဖို့ ဖြစ်ပါတယ်။
*   **အားနည်းချက်:** ပုံကို Max Pooling နဲ့ အကြိမ်ကြိမ် သေးလိုက်တဲ့အတွက် "ဘယ်နေရာမှာ (Where)" ရှိလဲဆိုတဲ့ တိကျတဲ့ တည်နေရာနဲ့ အနားသတ်မျဉ်း (Spatial Information) တွေ ပျောက်ဆုံးသွားပါတယ်။

### (B) Decoder (ညာဘက်အခြမ်း - ပြန်လည်ချဲ့ကားခြင်း)
*   **လုပ်ဆောင်ချက်:** သေးငယ်သွားတဲ့ Feature Map တွေကို မူလပုံအရွယ်အစား ပြန်ရောက်အောင် **Up-sampling (သို့မဟုတ် Transposed Convolution)** ကို သုံးပြီး တဖြည်းဖြည်း ပြန်ချဲ့ကားပါတယ်။
*   **ရည်ရွယ်ချက်:** ပျောက်ဆုံးသွားတဲ့ နေရာအချက်အလက် (Where) တွေကို ပြန်လည်တည်ဆောက်ပြီး၊ Pixel တစ်ခုချင်းစီအတွက် အဖြေထုတ်ပေးဖို့ ဖြစ်ပါတယ်။

### (C) Skip Connections (The Magic - ပေါင်းကူးတံတားများ) ✨
ဒါဟာ U-Net ရဲ့ အသက်သွေးကြောပါပဲ။ Decoder က ပုံကို ပြန်ချဲ့တဲ့အခါ، သူချဲ့လိုက်တဲ့ပုံဟာ ဝါးတားတား ဖြစ်နေပြီး အနားသတ်မျဉ်းတွေ မပြတ်သားတော့ပါဘူး။ 
ဒီပြဿနာကို ဖြေရှင်းဖို့ **"ဘယ်ဘက်အခြမ်း (Encoder) မှာ မသေးခင်ကတည်းက ရှိနေတဲ့ အရည်အသွေးမြင့် ပုံရိပ်တွေကို، ညာဘက်အခြမ်း (Decoder) ဆီကို တံတားထိုးပြီး တိုက်ရိုက် လှမ်းပေါင်းထည့် (Concatenate) လိုက်ပါတယ်။"** ဒါကို Skip Connections လို့ ခေါ်ပါတယ်။

ဒီနည်းပညာကြောင့် U-Net ဟာ ကင်ဆာဆဲလ်လေးတွေရဲ့ အနားသတ်ကို ကွက်တိကျအောင် ဆွဲထုတ်ပေးနိုင်သွားတာ ဖြစ်ပါတယ်။

![U-Net Architecture](https://via.placeholder.com/800x400?text=U-Net%3A+Encoder+%28Down%29+-%3E+Bottleneck+-%3E+Decoder+%28Up%29+%2B+Skip+Connections)
*(မှတ်ချက် - ဤနေရာတွင် U-Net ၏ "U" ပုံသဏ္ဌာန် Architecture ကို ပြသသော ပုံထည့်သွင်းရန်)*

## 💻 ၂။ PyTorch ဖြင့် U-Net ၏ အလုပ်လုပ်ပုံကို နားလည်ခြင်း

U-Net ရဲ့ Skip Connection အလုပ်လုပ်ပုံကို PyTorch Code အတိုလေးနဲ့ မြင်သာအောင် ပြသပေးပါမယ်။

```python
import torch
import torch.nn as nn

# ဥပမာ - U-Net ၏ ကြားအလွှာတစ်ခု (Encoder မှ Decoder သို့ ကူးပြောင်းခြင်း)
class UNet_Block_Example(nn.Module):
    def __init__(self):
        super().__init__()
        
        # ၁။ Encoder အပိုင်း (ပုံကို သေးစေသည်)
        self.encoder_conv = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2) # ပုံအရွယ်အစား တစ်ဝက်သေးသွားမည်
        
        # ၂။ Decoder အပိုင်း (ပုံကို ပြန်ချဲ့မည်)
        # ConvTranspose2d သည် MaxPool ၏ ပြောင်းပြန် (Up-sampling) ဖြစ်သည်
        self.upconv = nn.ConvTranspose2d(128, 64, kernel_size=2, stride=2)
        
    def forward(self, x):
        # --- Encoder Path ---
        # ဥပမာ: x ၏ shape သည်[Batch, 64, 100, 100] ဖြစ်သည်
        enc_features = self.encoder_conv(x) # shape: [Batch, 128, 100, 100]
        
        # pooling ကြောင့် [Batch, 128, 50, 50] သို့ သေးသွားမည်
        down_sampled = self.pool(enc_features) 
        
        # --- Decoder Path ---
        # upconv ကြောင့် မူလအရွယ်အစား [Batch, 64, 100, 100] သို့ ပြန်ရောက်မည်
        up_sampled = self.upconv(down_sampled) 
        
        # --- Skip Connection (The Magic) ---
        # အသေးစိတ်အချက်အလက်များ မပျောက်ဆုံးစေရန် Encoder မှ ပုံနှင့် ပြန်ချဲ့ထားသော ပုံကို ပေါင်းစပ်သည်
        # dim=1 ဆိုသည်မှာ Channel အလိုက် ပေါင်းစပ် (Concatenate) ခြင်းဖြစ်သည်
        final_output = torch.cat([up_sampled, enc_features], dim=1) 
        # ရလဒ် Shape:[Batch, 128, 100, 100]
        
        return final_output

# မှတ်ချက်: ဤသည်မှာ U-Net ၏ သဘောတရားကို နားလည်စေရန် အလွယ်ကူဆုံး ရေးပြထားခြင်းဖြစ်ပါသည်။
```

## 📏 ၃။ Segmentation ကို တိုင်းတာခြင်း (Evaluation Metrics)

Classification မှာ ရာခိုင်နှုန်း (Accuracy) နဲ့ တိုင်းပါတယ်။ ဒါပေမယ့် Medical Segmentation မှာ Accuracy ကို သုံးရင် **အလွန်ဆိုးရွားတဲ့ အမှားတွေ (Accuracy Paradox)** ဖြစ်တတ်ပါတယ်။

**ဘာကြောင့်လဲ?**
ဥပမာ - ဦးနှောက် MRI ပုံကြီး တစ်ပုံမှာ ကင်ဆာအကျိတ် (Tumor) လေးက ပုံတစ်ခုလုံးရဲ့ `1%` ပဲ ရှိတယ် ဆိုပါစို့။ AI က ပုံတစ်ပုံလုံးကို "အကျိတ်မရှိဘူး (Background)" လို့ အကုန်လုံး အမည်းရောင် ခြယ်ပေးလိုက်ရင်တောင်မှ၊ ပုံရဲ့ `99%` က မှန်နေတဲ့အတွက် AI ရဲ့ Accuracy က `99%` ဖြစ်နေပါလိမ့်မယ်။ ဒါပေမယ့် တကယ်တမ်း အကျိတ်ကို လုံးဝ မရှာနိုင်ခဲ့ပါဘူး။

ဒီပြဿနာကို ဖြေရှင်းဖို့ အောက်ပါ Metrics ၂ ခုကို အသုံးပြုရပါတယ်။

### (A) Dice Coefficient (သို့မဟုတ် F1-Score)
ဆေးဘက်ဆိုင်ရာ သုတေသနတွေမှာ အများဆုံး သုံးပါတယ်။ သူက AI ခန့်မှန်းလိုက်တဲ့ Mask နဲ့ တကယ့် အဖြေမှန် Mask ကြားမှာ ဘယ်လောက် ထပ်တူကျလဲ ဆိုတာကို တိုင်းတာတာပါ။ Background အမည်းရောင် အကျယ်ကြီးတွေကို ထည့်မတွက်ပါဘူး။
*   **ဖော်မြူလာ:** $\frac{2 \times (\text{Overlap Area})}{\text{Total Pixels in Both Masks}}$
*   တန်ဖိုး $0$ ကနေ $1$ ထိ ရှိပြီး၊ $1$ ဆိုလျှင် 100% ကွက်တိကျသည်ဟု အဓိပ္ပာယ်ရသည်။

### (B) Pixel-level IoU (Intersection over Union)
Object Detection မှာ Bounding Box ၂ ခု ထပ်တာကို တွက်သလိုပဲ၊ ဒီမှာတော့ Mask (အရောင်ခြယ်ထားတဲ့ ဧရိယာ) ၂ ခု ဘယ်လောက်ထပ်လဲ ဆိုတာကို တွက်တာ ဖြစ်ပါတယ်။
*   **ဖော်မြူလာ:** $\frac{\text{Area of Overlap}}{\text{Area of Union}}$

*(လုပ်ငန်းခွင်မှာ Model တော်/မတော် ကို Dice Score နဲ့ IoU ကို ကြည့်ပြီး အဆုံးအဖြတ် ပေးကြပါတယ်။)*

## 📝 အနှစ်ချုပ် (Key Takeaways)
1. **Medical Segmentation** သည် Bounding Box ထက် ပိုမိုတိကျသော Pixel-level ခွဲခြားမှု လိုအပ်သော ကင်ဆာအကျိတ်များ၊ ဆဲလ်များ ရှာဖွေရာတွင် အသုံးပြုသည်။
2. **U-Net** သည် ဆေးဘက်ဆိုင်ရာ ပုံရိပ်များအတွက် အကောင်းဆုံး Architecture ဖြစ်ပြီး **Encoder (ကျုံ့ဝင်ခြင်း)** နှင့် **Decoder (ပြန်လည်ချဲ့ကားခြင်း)** တို့ ပါဝင်သည်။
3. **Skip Connections** သည် Encoder မှ အသေးစိတ် အချက်အလက် (High-resolution features) များကို Decoder သို့ တိုက်ရိုက် ပေါင်းကူးပေးသဖြင့် အနားသတ်မျဉ်းများကို ကွက်တိကျစေသည်။
4. Segmentation တွင် Background ကြီးမားလွန်းသဖြင့် Accuracy အစား **Dice Coefficient** နှင့် **IoU** တို့ကို အသုံးပြု၍ မော်ဒယ်ကို တိုင်းတာရသည်။
