# 🚀 PART 4: Advanced Vision Tasks (Industry အဆင့် အသုံးချနည်းပညာများ)

# 📘 Chapter 7.1: Introduction to Image Segmentation (ပုံရိပ်များကို အတိအကျ ပိုင်းခြားခြင်း)

အရင် Part 3 မှာ သင်ခဲ့တဲ့ Object Detection (YOLO) တွေက အရာဝတ္ထုတွေကို **လေးထောင့်ဘောင် (Bounding Boxes)** တွေနဲ့ ပြသပါတယ်။ ဒါဟာ လုံခြုံရေးကင်မရာမှာ လူရေတွက်တာမျိုးတွေအတွက် အလွန်ကောင်းမွန်ပါတယ်။ 

ဒါပေမယ့် Bounding Box တွေဟာ အရာဝတ္ထုရဲ့ "ပုံသဏ္ဌာန် အတိအကျ" ကို မသိနိုင်ပါဘူး။ လေးထောင့်ဘောင်ထဲမှာ နောက်ခံ (Background) တွေ အများကြီး ရောပါနေတတ်ပါတယ်။
*   **Self-driving Cars (အလိုအလျောက် မောင်းနှင်သော ကားများ):** လမ်းမကြီးက ကွေ့ကောက်နေတဲ့အခါ လေးထောင့်ဘောင် ခတ်ပြလို့ မရပါဘူး။ လမ်းရဲ့ နယ်နိမိတ်မျဉ်းကို အတိအကျ သိဖို့ လိုအပ်ပါတယ်။
*   **Medical Imaging (ဆေးဘက်ဆိုင်ရာ ပုံရိပ်များ):** ကင်ဆာအကျိတ် (Tumor) ကို ခွဲခြမ်းစိတ်ဖြာတဲ့အခါ လေးထောင့်ဘောင် ခတ်ရုံနဲ့ မလုံလောက်ဘဲ၊ အကျိတ်ရဲ့ ဧရိယာ (Area) ဘယ်လောက် ကြီးသလဲဆိုတာကို Pixel တစ်ကွက်ချင်းစီ အတိအကျ တွက်ထုတ်ဖို့ လိုအပ်ပါတယ်။

ဒီလို ပုံထဲမှာရှိတဲ့ Pixel တစ်ခုချင်းစီဟာ ဘာကိုကိုယ်စားပြုသလဲ ဆိုတာကို အတိအကျ ခွဲခြားပေးတဲ့ နည်းပညာကို **Image Segmentation (ပုံရိပ်ပိုင်းခြားခြင်း)** လို့ ခေါ်ပါတယ်။

Image Segmentation မှာ အဓိကအားဖြင့် အမျိုးအစား ၃ မျိုး ရှိပါတယ်။

---

## 🎨 ၁။ Semantic Segmentation (အမျိုးအစားတူလျှင် အရောင်တူ ခြယ်ခြင်း)

Semantic Segmentation ရဲ့ ရည်ရွယ်ချက်ကတော့ **ပုံထဲမှာရှိတဲ့ Pixel အားလုံးကို ဘာအမျိုးအစားလဲ ဆိုတာ ခွဲခြားပေးဖို့** ဖြစ်ပါတယ်။

*   **အလုပ်လုပ်ပုံ:** ပုံထဲက Pixel တွေအားလုံးကို လိုက်စစ်ပါတယ်။ လမ်းမ (Road) Pixel ဆိုရင် အပြာရောင်၊ ကား (Car) ဆိုရင် အနီရောင်၊ သစ်ပင် (Tree) ဆိုရင် အစိမ်းရောင် စသဖြင့် ဆေးရောင်ခြယ် (Mask) ပေးလိုက်ပါတယ်။
*   **အဓိက အားနည်းချက်:** သူက "Class (အမျိုးအစား)" ကိုပဲ သိပါတယ်။ "အရေအတွက် (Instances)" ကို မခွဲခြားနိုင်ပါဘူး။ 
    *   *ဥပမာ - ကား ၃ စီး ကပ်ရပ်နေတယ်ဆိုပါစို့။ Semantic Segmentation က အဲ့ဒီ ကား ၃ စီးလုံးကို "အနီရောင် (Car Class)" ဆိုပြီး တစ်ဆက်တည်း ခြယ်ပစ်လိုက်ပါတယ်။ ကား ၁၊ ကား ၂၊ ကား ၃ ဆိုပြီး သီးခြားစီ မခွဲပေးနိုင်ပါဘူး။*
*   **အသုံးပြုမှု:** Autonomous Driving (ကားမောင်းစနစ်) တွေမှာ လမ်း၊ ပလက်ဖောင်း၊ ကောင်းကင် စတဲ့ Background တွေကို ခွဲခြားသိမြင်ဖို့ အဓိက အသုံးပြုပါတယ်။

---

## ✂️ ၂။ Instance Segmentation (အရာဝတ္ထုတစ်ခုချင်းစီကို သီးခြားခွဲထုတ်ခြင်း)

Instance Segmentation ကတော့ Object Detection နဲ့ Semantic Segmentation ကို ပေါင်းစပ်ထားတာ ဖြစ်ပါတယ်။

*   **အလုပ်လုပ်ပုံ:** သူက "ရေတွက်လို့ရတဲ့ အရာဝတ္ထု (Things)" တွေကိုပဲ အာရုံစိုက်ပါတယ်။ ကား ၃ စီး ကပ်ရပ်နေရင် **ကား ၁ စီးချင်းစီကို အရောင်မတူတဲ့ Mask ၃ ခု (ဥပမာ - အနီ၊ အပြာ၊ အဝါ) သီးခြားစီ ခွဲခြားပေးပါတယ်။**
*   **အဓိက အားနည်းချက်:** သူက နောက်ခံ (Background) တွေဖြစ်တဲ့ ကောင်းကင်၊ လမ်းမ၊ မြက်ခင်း တွေကို ဂရုမစိုက်ပါဘူး (လုံးဝ ရှာမပေးပါဘူး)။ သူသိတဲ့ လူ၊ ကား၊ ခွေး စတဲ့ Object တွေကိုပဲ Mask ဖြတ်ပေးတာ ဖြစ်ပါတယ်။
*   **အသုံးပြုမှု:** ဆေးရုံက သွေးဆဲလ်လေးတွေကို ရေတွက်ခြင်း၊ စက်ရုံတွေမှာ ပစ္စည်းအရေအတွက်ကို တိတိကျကျ ရေတွက်ခြင်း တွေမှာ အသုံးပြုပါတယ်။ (နာမည်အကြီးဆုံး Model မှာ **Mask R-CNN** နှင့် **YOLO-Seg** တို့ ဖြစ်ကြသည်)။

---

## 🧩 ၃။ Panoptic Segmentation (အရာအားလုံးကို ပြီးပြည့်စုံစွာ ပိုင်းခြားခြင်း)

Panoptic ဆိုတာ "အရာအားလုံးကို မြင်နိုင်သော" လို့ အဓိပ္ပာယ်ရပါတယ်။ သူက **Semantic ရော၊ Instance ရော နှစ်ခုလုံးရဲ့ အားသာချက်တွေကို ပေါင်းစပ်ထားတဲ့ အမြင့်ဆုံးအဆင့် Segmentation ဖြစ်ပါတယ်။**

ဒါကို နားလည်ဖို့ Computer Vision ရဲ့ အခြေခံဝေါဟာရ ၂ ခုကို သိရပါမယ်-
1.  **Things (ရေတွက်၍ရသော အရာများ):** လူ၊ ကား၊ တိရစ္ဆာန် စသည်ဖြင့် အကောင်လိုက်၊ အခုလိုက် ရေတွက်လို့ရတဲ့ အရာတွေပါ။
2.  **Stuff (ရေတွက်၍မရသော အရာများ):** ကောင်းကင်၊ မြက်ခင်း၊ လမ်းမ စတဲ့ ပုံသဏ္ဌာန် အတိအကျမရှိဘဲ ဖြန့်ကျက်နေတဲ့ နောက်ခံတွေပါ။

*   **အလုပ်လုပ်ပုံ:** Panoptic Segmentation က ပုံထဲမှာရှိတဲ့ Pixel တိုင်းကို အလွတ်မပေးပါဘူး။ 
    *   **"Things"** တွေကို တွေ့ရင် Instance Segmentation လိုမျိုး တစ်ခုချင်းစီ (ကား ၁၊ ကား ၂) သီးခြားစီ အရောင်ခွဲခြယ်ပါတယ်။
    *   **"Stuff"** တွေကို တွေ့ရင်တော့ Semantic Segmentation လိုမျိုး (လမ်း၊ ကောင်းကင်) ဆိုပြီး အမည်တပ် အရောင်ခြယ်ပေးပါတယ်။
*   **အသုံးပြုမှု:** Self-driving Cars တွေရဲ့ မျိုးဆက်သစ် AI (Tesla Vision) တွေမှာ ပတ်ဝန်းကျင် တစ်ခုလုံးကို ၁၀၀% နားလည်ဖို့အတွက် Panoptic Segmentation ကို မဖြစ်မနေ အသုံးပြုလာကြပါတယ်။

---

## 📊 နှိုင်းယှဉ်ချက် ဇယား (Quick Summary)

| Feature | Semantic Segmentation | Instance Segmentation | Panoptic Segmentation |
| :--- | :--- | :--- | :--- |
| **ရည်ရွယ်ချက်** | Pixel တိုင်းကို Class (အမျိုးအစား) ခွဲရန် | Object တစ်ခုချင်းစီကို သီးခြား (ID) ခွဲထုတ်ရန် | အရာအားလုံးကို ပြီးပြည့်စုံစွာ ခွဲခြားရန် |
| **ကပ်နေသော ကား ၂ စီး** | အတုံးကြီး တစ်တုံးတည်းအဖြစ် မြင်သည် | ကား ၁ နှင့် ကား ၂ အဖြစ် သီးခြားစီ မြင်သည် | ကား ၁ နှင့် ကား ၂ အဖြစ် သီးခြားစီ မြင်သည် |
| **နောက်ခံ (Sky, Road)** | ခွဲခြားပေးသည် (အရောင်ခြယ်သည်) | လျစ်လျူရှုသည် (အမည်းရောင်ချန်ထားသည်) | ခွဲခြားပေးသည် (အရောင်ခြယ်သည်) |
| **ဥပမာ Models** | U-Net, DeepLab, FCN | Mask R-CNN, YOLOv8-Seg | DETR, Panoptic FPN |

## 📝 အနှစ်ချုပ် (Key Takeaways)
1. **Segmentation** ဆိုသည်မှာ Bounding Box များအစား ပုံထဲရှိ Pixel တစ်ခုချင်းစီကို တိကျစွာ ခွဲခြားအရောင်ခြယ်ပေးသော နည်းပညာဖြစ်သည်။
2. **Semantic Segmentation** သည် Background များကိုပါ ခွဲခြားနိုင်သော်လည်း၊ ကပ်နေသော အမျိုးအစားတူ အရာဝတ္ထုများကို ခွဲခြားမသိနိုင်ပါ။
3. **Instance Segmentation** သည် Background များကို လျစ်လျူရှုထားပြီး၊ အရာဝတ္ထု (Objects) တစ်ခုချင်းစီကိုသာ သီးခြားစီ (Mask) ဖြတ်ထုတ်ပေးသည်။
4. **Panoptic Segmentation** သည် Pixel အားလုံးကို နားလည်အောင် ခွဲခြမ်းပေးသည့် အဆင့်မြင့်ဆုံး Segmentation နည်းပညာဖြစ်သည်။
