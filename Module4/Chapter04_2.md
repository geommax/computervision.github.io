# 📘 Chapter 4.2: Activation & Loss Functions (ဆုံးဖြတ်ချက်ချခြင်းနှင့် မှားယွင်းမှုကို တိုင်းတာခြင်း)

အရင်အခန်းတုန်းက Neuron လေးတစ်ခုဟာ ဝင်လာတဲ့ Input တွေကို Weight တွေနဲ့မြှောက်၊ Bias ပေါင်းပြီး $Z = (X \cdot W) + b$ ဆိုတဲ့ Linear Transformation တွက်ချက်မှု လုပ်တယ်ဆိုတာကို လေ့လာခဲ့ပါတယ်။ 

ဒါပေမယ့် အဲ့ဒီထွက်လာတဲ့ $Z$ တန်ဖိုးဟာ အလွန်ကြီးတဲ့ အပေါင်းဂဏန်း (ဥပမာ 1000) လည်း ဖြစ်နိုင်သလို၊ အလွန်ငယ်တဲ့ အနှုတ်ဂဏန်း (ဥပမာ -500) လည်း ဖြစ်သွားနိုင်ပါတယ်။ ဒီဂဏန်းကြီးကို "ဒါဟာ ခွေးလား၊ ကြောင်လား" ဆိုတဲ့ ဆုံးဖြတ်ချက်အဖြစ် ပြောင်းလဲဖို့နဲ့၊ လက်တွေ့ကမ္ဘာက ရှုပ်ထွေးတဲ့ ပြဿနာတွေကို ဖြေရှင်းဖို့အတွက် **Activation Function** ဆိုတာ လိုအပ်လာပါတယ်။

## ⚡ ၁။ Activation Function ဆိုတာ ဘာလဲ? (The Decision Maker)

ဇီဝဗေဒအရ လူ့ဦးနှောက်က ဆဲလ်လေးတွေဟာ လျှပ်စစ်လှိုင်းတစ်ခု ဝင်လာတိုင်း နောက်တစ်ကောင်ဆီကို အမြဲတမ်း ဆက်မပို့ပါဘူး။ ဝင်လာတဲ့ လှိုင်းက လုံလောက်တဲ့ အားတစ်ခု (Threshold) ပြည့်မှသာ "Fire" လုပ် (ဆက်ပို့) တာပါ။ 

အဲ့ဒီသဘောတရားအတိုင်းပါပဲ။ Artificial Neuron တွေမှာလည်း ထွက်လာတဲ့ $Z$ တန်ဖိုးကို **"နောက်တစ်ဆင့်ကို ဆက်ပို့သင့်/မပို့သင့်"** (သို့မဟုတ်) **"ဘယ်လောက်ရာခိုင်နှုန်း သေချာသလဲ"** ဆိုတဲ့ ပုံစံမျိုး ပြောင်းလဲပေးတာကို **Activation Function** လို့ ခေါ်ပါတယ်။ သူက Network ကြီးထဲကို **Non-linearity (မျဉ်းဖြောင့်မဟုတ်သော ရှုပ်ထွေးမှုများ)** ထည့်သွင်းပေးလိုက်တာ ဖြစ်ပါတယ်။ 

*(မှတ်ချက် - Activation Function သာ မပါရင် Neural Network ကြီး အလွှာ ၁၀၀ ရှိလည်း မျဉ်းဖြောင့်ညီမျှခြင်း တစ်ကြောင်းတည်းနဲ့ အတူတူပဲ ဖြစ်နေမှာပါ)*။

---

## 📈 ၂။ အသုံးအများဆုံး Activation Function ၃ မျိုး

Computer Vision နဲ့ Deep Learning မှာ အဓိက အသုံးပြုတဲ့ Activation Function ၃ ခု ရှိပါတယ်။

### (A) Sigmoid Function (စစ်ဂမွိုက်)
*   **အလုပ်လုပ်ပုံ:** ဝင်လာသမျှ ဂဏန်းတွေကို **0 နှင့် 1 ကြား** ရောက်အောင် ညှစ်ချပစ်လိုက်ပါတယ်။
*   **အသုံးဝင်ပုံ:** 1 ကို "ဟုတ်တယ် (True)"၊ 0 ကို "မဟုတ်ဘူး (False)" လို့ သတ်မှတ်နိုင်တဲ့အတွက် **Binary Classification (အဖြေ ၂ ခုထဲက တစ်ခုရွေးရသော ပြဿနာများ - ဥပမာ - ခွေးလား ကြောင်လား၊ လူပါလား မပါဘူးလား)** တွေရဲ့ နောက်ဆုံး Output Layer မှာ အများဆုံး သုံးပါတယ်။
*   **အားနည်းချက်:** Network အလွှာတွေ အရမ်းများလာရင် သင်ယူမှု ရပ်တန့်သွားတတ်တဲ့ ပြဿနာ (Vanishing Gradient) ရှိတဲ့အတွက် ကြားအလွှာ (Hidden Layers) တွေမှာ အခုခေတ် မသုံးကြတော့ပါဘူး။

### (B) ReLU (Rectified Linear Unit - ရီလူး)
*   **အလုပ်လုပ်ပုံ:** အလွန်ရိုးရှင်းပါတယ်။ ဝင်လာတဲ့ဂဏန်းက **အနှုတ်ဖြစ်နေရင် 0** အဖြစ် ပြောင်းပစ်လိုက်ပြီး၊ **အပေါင်းဖြစ်နေရင်တော့ မူလဂဏန်းအတိုင်း** ဆက်လက် ထုတ်ပေးပါတယ်။ $f(x) = \max(0, x)$
*   **အသုံးဝင်ပုံ:** ယနေ့ခေတ် Deep Learning (CNNs) မော်ဒယ်တိုင်းရဲ့ **Hidden Layers တွေ အားလုံးမှာ ReLU ကိုပဲ Default အနေနဲ့ အသုံးပြုကြပါတယ်။** သူက တွက်ချက်ရတာ အလွန်မြန်ဆန်ပြီး Vanishing Gradient ပြဿနာကိုလည်း ဖြေရှင်းပေးနိုင်လို့ပါ။

### (C) Softmax Function (ဆော့ဖ်မတ်စ်)
*   **အလုပ်လုပ်ပုံ:** ဂဏန်းတွေကို 0 နဲ့ 1 ကြား ပြောင်းပေးတဲ့အပြင်၊ **ထွက်လာတဲ့ တန်ဖိုးအားလုံး ပေါင်းလိုက်ရင် 1 (100%) ကွက်တိ ဖြစ်အောင်** အချိုးကျ တွက်ချက်ပေးပါတယ်။
*   **အသုံးဝင်ပုံ:** ရွေးချယ်စရာ အဖြေ ၃ ခုနဲ့အထက် ရှိတဲ့ **Multi-class Classification (ဥပမာ - ကား၊ ဆိုင်ကယ်၊ လူ၊ စက်ဘီး - ၄ မျိုးထဲက တစ်ခုခု ခွဲခြားရသော ပြဿနာ)** တွေရဲ့ နောက်ဆုံး Output Layer မှာ အသုံးပြုပါတယ်။ (ဥပမာ - ကား=70%, ဆိုင်ကယ်=20%, လူ=10%)။

*(မှတ်ချက် - ဤနေရာတွင် Sigmoid နှင့် ReLU ၏ ဂရပ်ဖ်ပုံများ ထည့်သွင်းရန်)*

## ⚖️ ၃။ Loss Function ဆိုတာ ဘာလဲ? (အမှားကို တိုင်းတာခြင်း)

AI Model တစ်ခုကို စပြီး Train လုပ်ခါစမှာ သူ့ရဲ့ Weights တွေနဲ့ Biases တွေက Random (ကျပန်း) ဂဏန်းတွေ ဖြစ်နေပါသေးတယ်။ 
ဒါကြောင့် ခွေးပုံတစ်ပုံကို ပြလိုက်တဲ့အခါ သူက "ဒါ ကြောင်ဖြစ်ဖို့ 80% သေချာတယ်" လို့ အဖြေမှားကြီး ထုတ်ပေးပါလိမ့်မယ်။

အဲ့ဒီအချိန်မှာ ဆရာလုပ်တဲ့သူက **"မင်း အဖြေမှားနေတယ်၊ တကယ့်အဖြေမှန် (Ground Truth) က ခွေး 100% ကွ။ မင်းရဲ့ အဖြေက ဘယ်လောက်တောင် လွဲချော်နေလဲဆိုရင်..."** လို့ ပြောပြဖို့ လိုပါတယ်။ အဲ့ဒီ **"ဘယ်လောက် လွဲချော်နေလဲ (မှားယွင်းနေလဲ)"** ဆိုတာကို သင်္ချာနည်းနဲ့ တွက်ထုတ်ပေးတဲ့ ပုံသေနည်းကို **Loss Function (သို့မဟုတ် Cost Function)** လို့ ခေါ်ပါတယ်။

> 🎯 **AI ၏ ပန်းတိုင် (The Goal of AI):**
> Model တစ်ခု လေ့ကျင့်တယ် (Training) ဆိုတာ တခြားမဟုတ်ပါဘူး။ အဲ့ဒီ **Loss (မှားယွင်းမှု) တန်ဖိုး သုည (0) နား ကပ်သွားအောင် (တတ်နိုင်သမျှ အနည်းဆုံးဖြစ်အောင်)** Weights တွေကို ပြုပြင်ပြောင်းလဲနေတဲ့ လုပ်ငန်းစဉ်ကြီးပဲ ဖြစ်ပါတယ်။

---

## 📏 ၄။ Computer Vision တွင် အသုံးများသော Loss Functions များ

ပြဿနာ အမျိုးအစားပေါ် မူတည်ပြီး သုံးရမယ့် Loss Function ကွာခြားပါတယ်။

1.  **Cross-Entropy Loss:** 
    *   **Classification (ခွဲခြားသိမြင်ခြင်း)** ပြဿနာတွေမှာ သုံးပါတယ်။ 
    *   Model က ထုတ်ပေးလိုက်တဲ့ ရာခိုင်နှုန်း (Probability) နဲ့ တကယ့် အဖြေမှန် ရာခိုင်နှုန်း (0 သို့မဟုတ် 1) ကြားက ကွာဟချက်ကို တွက်ပေးတာပါ။ ခွေးပုံကို ကြောင် 99% လို့ ယုံကြည်လေလေ၊ Cross-Entropy Loss က ကြီးလေလေ ဖြစ်ပါတယ်။
2.  **Mean Squared Error (MSE) / L2 Loss:** 
    *   **Regression (ဂဏန်းအတိအကျ ခန့်မှန်းခြင်း)** ပြဿနာတွေမှာ သုံးပါတယ်။
    *   ဥပမာ - YOLO လို Object Detection တွေမှာ Bounding Box ရဲ့ Location `(x, y, width, height)` တွေ မှန်/မမှန် တိုင်းတာတဲ့အခါ MSE ကို အသုံးပြုပါတယ်။

## 💻 ၅။ NumPy ဖြင့် Activation ပြုလုပ်ကြည့်ခြင်း

Activation Functions တွေဟာ နာမည်သာ ခက်ပေမယ့် တကယ်တမ်း သင်္ချာနည်းအရ ဘယ်လောက် ရိုးရှင်းလဲ ဆိုတာကို NumPy Code လေးနဲ့ ကြည့်ကြရအောင်။

```python
import numpy as np

# Z ဆိုသည်မှာ (X*W) + b မှ ထွက်လာသော ကနဦး ရလဒ်များဖြစ်သည် (အနှုတ်များ၊ အပေါင်းများ ရောနေသည်)
z_values = np.array([-2.5, 0.0, 3.2, 1.5, -1.0])

# ၁။ ReLU Function ရေးသားခြင်း (အနှုတ်ဆိုလျှင် 0 ပြောင်းမည်)
def relu(z):
    return np.maximum(0, z)

# ၂။ Softmax Function ရေးသားခြင်း (အားလုံးပေါင်းလျှင် 1 (100%) ဖြစ်အောင် ပြောင်းမည်)
def softmax(z):
    exp_z = np.exp(z) # e^z ကို တွက်ခြင်း
    return exp_z / np.sum(exp_z)

# ရလဒ်များ ကြည့်ရှုခြင်း
print(f"Original Z Values: \n{z_values}\n")

print(f"After ReLU (Hidden Layer တွင်သုံးသည်): \n{relu(z_values)}\n") 
# Output:[0.  0.  3.2 1.5 0. ] (အနှုတ်များ 0 ဖြစ်သွားသည်ကို သတိပြုပါ)

print(f"After Softmax (Output Layer တွင်သုံးသည်): \n{np.round(softmax(z_values), 3)}\n")
# Output:[0.003 0.034 0.825 0.151 0.012]
# အားလုံးပေါင်းလိုက်ပါက 1 (100%) တိတိ ရရှိမည်ဖြစ်သည်။
```

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **Activation Functions** များသည် Neural Network များအား မျဉ်းဖြောင့် (Linear) အခြေအနေမှ သွေဖည်စေပြီး ရှုပ်ထွေးသော ပြဿနာများကို ဖြေရှင်းနိုင်အောင် ကူညီပေးသည်။
2.  **ReLU** ကို Hidden Layers များတွင် အများဆုံး အသုံးပြုပြီး၊ **Sigmoid** နှင့် **Softmax** တို့ကို ရလဒ်ရာခိုင်နှုန်း (Probability) ထုတ်ပေးသော Output Layers များတွင် အသုံးပြုသည်။
3.  **Loss Function** သည် Model ၏ အဖြေနှင့် အဖြေမှန်ကြားရှိ "မှားယွင်းမှု ပမာဏ" ကို တိုင်းတာပေးသော ပုံသေနည်း ဖြစ်သည်။
4.  Computer Vision တွင် Classification အတွက် **Cross-Entropy Loss** ကို သုံးလေ့ရှိပြီး၊ Bounding Box များ ရှာဖွေခြင်းအတွက် **MSE Loss** ကို အသုံးများသည်။
