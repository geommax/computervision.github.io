# 📘 Chapter 4.3: Optimizers & Backpropagation (အမှားများမှ သင်ခန်းစာယူ၍ ပိုတော်လာအောင် လေ့ကျင့်ခြင်း)

အရင်အခန်း (Chapter 4.2) မှာ AI Model တစ်ခုက သူ့ရဲ့အဖြေမှားသွားတဲ့အခါ **Loss Function** ကနေတစ်ဆင့် **"ငါ ဘယ်လောက်တောင် မှားသွားလဲ (Error)"** ဆိုတာကို တွက်ထုတ်ပေးတယ်လို့ လေ့လာခဲ့ပါတယ်။ 

ဒါဆိုရင် အဲ့ဒီအမှား (Loss) ကိုသိပြီဆိုပါစို့။ **"ငါ့ရဲ့ Weight တွေနဲ့ Bias တွေကို ဘယ်လို ပြန်ပြင်ရမလဲ?"** ဒါဟာ Neural Network တွေရဲ့ အကြီးမားဆုံး လျှို့ဝှက်ချက်ပါပဲ။ ဒီအခန်းမှာ AI တွေ ဘယ်လို "သင်ယူ (Learn)" သလဲ ဆိုတဲ့ လုပ်ငန်းစဉ်ကြီးကို အသေးစိတ် လေ့လာသွားပါမယ်။

---

## ⛰️ ၁။ Gradient Descent (တောင်အောက်သို့ ဆင်းခြင်း သဘောတရား)

AI ရဲ့ ပန်းတိုင်က **Loss (အမှား) တန်ဖိုး အနည်းဆုံးဖြစ်အောင်** ရှာဖို့ပါ။ ဒီလုပ်ငန်းစဉ်ကို မျက်လုံးပိတ်ပြီး တောင်ပေါ်ကနေ အောက်ခြေ (ချိုင့်ဝှမ်း) ကို ဆင်းတဲ့ လူတစ်ယောက်နဲ့ တင်စားလေ့ရှိပါတယ်။

*   **တောင်ပေါ်ရောက်နေခြင်း:** Loss တန်ဖိုး အရမ်းများနေတာပါ။ (အဖြေတွေ အကုန်မှားနေသည်)။
*   **ချိုင့်ဝှမ်း (Minimum):** Loss တန်ဖိုး အနည်းဆုံး နေရာပါ။ (အဖြေတွေ အကုန်မှန်နေသည်)။
*   မျက်လုံးပိတ်ထားတဲ့ လူဟာ အောက်ခြေကို ရောက်ဖို့အတွက် ခြေထောက်နဲ့ မြေကြီးရဲ့ **ဆင်ခြေလျှော (Slope သို့မဟုတ် Gradient)** ကို စမ်းသပ်ရပါတယ်။ ဆင်ခြေလျှော စောက်တဲ့ဘက်ကို ခြေလှမ်းလှမ်းရင်းနဲ့ အောက်ခြေအထိ ရောက်အောင် ဆင်းရပါတယ်။

ဒီလို သင်္ချာနည်းအရ Gradient (ပြောင်းလဲမှုနှုန်း) ကို ရှာဖွေပြီး Loss အနည်းဆုံးနေရာကို သွားတဲ့ နည်းလမ်းကို **Gradient Descent** လို့ ခေါ်ပါတယ်။

---

## 👣 ၂။ Learning Rate (ခြေလှမ်းအကျယ်)

တောင်အောက်ကို ဆင်းတဲ့အခါ ခြေလှမ်း ဘယ်လောက်ကျယ်ကျယ် လှမ်းမလဲ ဆိုတာကို **Learning Rate ($\alpha$)** လို့ ခေါ်ပါတယ်။ ဒါဟာ AI Engineer တွေ ကိုယ်တိုင် သတ်မှတ်ပေးရတဲ့ (Hyperparameter) ဂဏန်းလေးတစ်ခု ဖြစ်ပါတယ်။ (ဥပမာ - `0.01` သို့မဟုတ် `0.001`)။

*   **Learning Rate အရမ်းကြီးလျှင် (Too High):** ခြေလှမ်း အရမ်းကျယ်တဲ့အတွက် ချိုင့်ဝှမ်းကို ကျော်ပြီး ဟိုဘက်တောင်ပေါ် ပြန်ရောက်သွားတတ်ပါတယ်။ (Loss က မကျဘဲ ပိုပိုများလာတတ်သည် - Overshooting)။
*   **Learning Rate အရမ်းသေးလျှင် (Too Low):** ခြေလှမ်းက ပုရွက်ဆိတ် လမ်းလျှောက်သလို ဖြစ်နေတဲ့အတွက် အောက်ခြေရောက်ဖို့ အချိန်အရမ်းကြာပါလိမ့်မယ်။

---

## 🛠️ ၃။ Optimizers (အမှားပြင်ဆင်ပေးသော အင်ဂျင်များ)

Gradient ကို တွက်ပြီး Weight တွေကို ပြုပြင်ပေးမယ့် စနစ်ကို **Optimizer** လို့ ခေါ်ပါတယ်။ ယနေ့ခေတ်မှာ အဓိက သုံးတဲ့ Optimizer ၂ ခု ရှိပါတယ်။

1.  **SGD (Stochastic Gradient Descent):** အခြေခံအကျဆုံး Optimizer ပါ။ Data အနည်းငယ်ချင်းစီကို ယူပြီး တဖြည်းဖြည်းချင်း တွက်ချက်သွားပါတယ်။
2.  **Adam (Adaptive Moment Estimation):** ယနေ့ခေတ် Computer Vision ရဲ့ **ရွှေစံနှုန်း (Gold Standard)** ပါပဲ။ သူက Gradient သက်သက်တင်မကဘဲ အဟုန် (Momentum) ကိုပါ ထည့်တွက်ပါတယ်။ လမ်းဖြောင့်ရင် မြန်မြန်လျှောက်ပြီး၊ လမ်းကွေ့ရင် အလိုလို ခြေလှမ်းပြန်ကျဉ်းပေးတဲ့ (Adaptive) စွမ်းရည် ရှိတဲ့အတွက် SGD ထက် အများကြီး ပိုမြန်၊ ပိုကောင်းပါတယ်။

---

## ⏪ ၄။ Backpropagation (အမှားကို နောက်ပြန် မျှဝေခြင်း)

Neural Network ကြီးတစ်ခုမှာ အလွှာတွေ၊ Weight တွေ သောင်းနဲ့ချီ ရှိပါတယ်။ 
နောက်ဆုံး Output မှာ မှားသွားပြီဆိုရင် **"ဒီအမှားဟာ ဘယ် Weight ကြောင့် ဖြစ်တာလဲ? ဘယ်သူ့မှာ အပြစ်ရှိတာလဲ?"** ဆိုတာကို နောက်ပြန် လိုက်ရှာရပါတယ်။ ဒါကို **Backpropagation (Backward Propagation of Errors)** လို့ ခေါ်ပါတယ်။

*   **Forward Pass:** Data တွေက အရှေ့ကိုသွားပြီး အဖြေထုတ်တယ်။ (Output)
*   **Loss Calculation:** အဖြေနဲ့ အဖြေမှန်ကို တိုက်စစ်ပြီး အမှားတွက်တယ်။ (Loss)
*   **Backward Pass (Backpropagation):** Calculus က **Chain Rule** ဆိုတဲ့ သဘောတရားကို သုံးပြီး၊ ထွက်လာတဲ့ အမှား (Loss) ကို နောက်ဆုံးအလွှာကနေ ပထမအလွှာအထိ ပြောင်းပြန် ပြန်သွားပြီး "မင်းရဲ့ Weight ကြောင့် 5% မှားတယ်၊ မင်းကိုတော့ Weight လျှော့ချရမယ်" စသဖြင့် အပြစ် (Error) တွေကို အချိုးကျ ခွဲဝေ သတ်မှတ်ပေးလိုက်ခြင်း ဖြစ်ပါတယ်။

## 💻 ၅။ NumPy ဖြင့် လက်တွေ့ Model သင်ယူပုံ အဆင့်ဆင့် (A Complete Training Step)

အထက်ပါ သဘောတရားတွေ အားလုံးကို ပေါင်းပြီး AI Model လေးတစ်ခု အမှားပြင်ဆင် သင်ယူသွားပုံကို NumPy သုံးပြီး တွက်ကြည့်ပါမယ်။ နားလည်လွယ်အောင် အရှင်းဆုံး Linear Model ($y = w \cdot x$) ကိုပဲ အသုံးပြုထားပါတယ်။

*   **ပုစ္ဆာ:** Input $x = 2.0$ ဝင်လာရင်၊ Output အဖြေမှန် $y = 10.0$ ထွက်ရပါမည်။
*   Model ရဲ့ ကနဦး Weight ကို (မသိလို့) Random $1.0$ ဟု ပေးထားပါမည်။

```python
import numpy as np

def train_one_step():
    # ၁။ ကနဦး အချက်အလက်များ (Setup)
    x = 2.0         # ဝင်လာမည့် Input (ဥပမာ - Pixel တန်ဖိုး)
    y_true = 10.0   # ဖြစ်သင့်သော အဖြေမှန် (Ground Truth)
    w = 1.0         # ကနဦး Weight (Random ပေးထားခြင်း)
    lr = 0.1        # Learning Rate (ခြေလှမ်းအကျယ်)

    print(f"--- Training မစခင် ---")
    print(f"ကနဦး Weight (w) = {w}")

    # ==========================================
    # အဆင့် ၁: FORWARD PASS (အဖြေ ခန့်မှန်းခြင်း)
    # ==========================================
    y_pred = w * x 
    print(f"\n[Step 1] Forward Pass: y_pred = {w} * {2.0} = {y_pred}")
    # (မှတ်ချက် - အဖြေမှန် 10 ရရမည်ကို 2 သာ ရနေသဖြင့် လုံးဝမှားနေပါသည်)

    # ==========================================
    # အဆင့် ၂: LOSS CALCULATION (အမှားကို တိုင်းတာခြင်း)
    # ==========================================
    # MSE (Mean Squared Error) သုံးမည်: Loss = (y_pred - y_true)^2
    loss = (y_pred - y_true)**2
    print(f"[Step 2] Loss (Error): ({y_pred} - {10.0})^2 = {loss}")

    # ==========================================
    # အဆင့် ၃: BACKPROPAGATION (Gradient ရှာဖွေခြင်း)
    # ==========================================
    # Calculus Derivative အရ: dLoss/dw = 2 * (y_pred - y_true) * x
    # ဆိုလိုသည်မှာ w ကို အပြောင်းအလဲလုပ်လျှင် Loss ဘယ်လောက်ပြောင်းသွားမည်ကို တွက်ခြင်းဖြစ်သည်
    gradient = 2 * (y_pred - y_true) * x
    print(f"[Step 3] Gradient (dLoss/dw) = {gradient}")
    # (Gradient အနှုတ်ထွက်နေခြင်းသည် Weight ကို ပေါင်းတင်ပေးရမည်ဟု အဓိပ္ပာယ်ရသည်)

    # ==========================================
    # အဆင့် ၄: WEIGHT UPDATE (Optimizer မှ အမှားပြင်ဆင်ခြင်း)
    # ==========================================
    # ဖော်မြူလာ: w_new = w_old - (Learning_Rate * Gradient)
    w = w - (lr * gradient)
    print(f"[Step 4] Weight ကို Update လုပ်ခြင်း: w_new = 1.0 - (0.1 * {gradient}) = {w}")

    # ==========================================
    # ရလဒ် စစ်ဆေးကြည့်ခြင်း
    # ==========================================
    print(f"\n--- 1 Step Training ပြီးနောက် ---")
    y_pred_new = w * x
    new_loss = (y_pred_new - y_true)**2
    print(f"Update လုပ်ပြီး Weight အသစ်ဖြင့် အဖြေ: y_pred = {y_pred_new}")
    print(f"Loss အသစ်: {new_loss} (မူလ 64 မှ 2.56 သို့ အံ့မခန်း ကျဆင်းသွားပါပြီ!)")

if __name__ == "__main__":
    train_one_step()
```

### 🧠 ဒီ Code လေးကနေ ဘာသိရသလဲ?
၁ ကြိမ် (1 Step) လေ့ကျင့်လိုက်တာနဲ့ Model က **"အိုကေ.. ငါ့ရဲ့ Weight က နည်းနေတာပဲ။ တင်ပေးမှ ရမယ်"** ဆိုတာကို တွက်ချက်သွားပြီး Weight တန်ဖိုးကို `1.0` ကနေ `4.2` ကို အလိုလို ပြင်ဆင်သွားပါတယ်။ ဒီလိုအဆင့်ကို အကြိမ် (Epochs) ၁၀၀ လောက် ဆက်လုပ်လိုက်ရင် Weight တန်ဖိုးက `5.0` (ကွက်တိ) ဖြစ်သွားပြီး၊ Loss က သုည (0) ဖြစ်သွားပါလိမ့်မယ်။ **ဒါဟာ AI တွေ သင်ယူတယ်ဆိုတဲ့ အဓိက လျှို့ဝှက်ချက်ပါပဲ။**

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **Gradient Descent:** Loss Function ရဲ့ အနည်းဆုံးအမှတ် (ချိုင့်ဝှမ်း) ကို ဆင်ခြေလျှောတိုင်းပြီး ရှာဖွေသော လုပ်ငန်းစဉ်။
2.  **Learning Rate ($\alpha$):** အမှားပြင်ဆင်သည့်အခါ ပြောင်းလဲမည့် ပမာဏ (ခြေလှမ်းအကျယ်) ကို ထိန်းချုပ်ပေးသော ဂဏန်း။
3.  **Backpropagation:** Output တွင် ဖြစ်ပေါ်သော အမှားများကို နောက်ပြန်လှည့်၍ Weight တစ်ခုချင်းစီထံ အပြစ်ခွဲဝေ သတ်မှတ်ပေးခြင်း။
4.  **Optimizer (Adam / SGD):** Backprop မှရလာသော Gradient များကို အသုံးပြု၍ Weights များကို အမှန်တကယ် Update လုပ်ပေးသော အင်ဂျင်။

> **🎉 Theory အပိုင်း ပြီးဆုံးပါပြီ!**
> အခုဆိုရင် Neural Network တွေရဲ့ သီအိုရီ အလုပ်လုပ်ပုံ (Forward Pass -> Loss -> Backprop -> Optimizer) အဆင့် ၄ ဆင့်လုံးကို နားလည်သွားပါပြီ။
