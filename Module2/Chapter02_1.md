# 📘 Chapter 2.1: How Computers See Images (ကွန်ပျူတာများ ပုံရိပ်တွေကို ဘယ်လိုနားလည်သလဲ?)

Computer Vision (CV) ကို မစတင်ခင်မှာ **"ပုံတစ်ပုံဆိုတာ တကယ်တော့ ဘာလဲ?"** ဆိုတာကို ကွန်ပျူတာရဲ့ အမြင်ဘက်ကနေ အရင်ဆုံး နားလည်ဖို့ လိုအပ်ပါတယ်။ ကျွန်တော်တို့က ပုံတစ်ပုံကို ကြည့်လိုက်ရင် လူ၊ ကား၊ သစ်ပင် စသဖြင့် အရာဝတ္ထုတွေကို မြင်ပေမယ့်၊ ကွန်ပျူတာကတော့ အဲ့ဒီလို မမြင်ပါဘူး။ ကွန်ပျူတာအတွက်တော့ ပုံတစ်ပုံဆိုတာ **ဂဏန်းတွေ စီတန်းထားတဲ့ ဇယားကွက်ကြီး (Matrix of Numbers)** တစ်ခုသာ ဖြစ်ပါတယ်။

ဒီအခန်းမှာ အဲ့ဒီ ဇယားကွက်ကြီး ဘယ်လိုဖွဲ့စည်းထားလဲ ဆိုတာကို အသေးစိတ် လေ့လာသွားပါမယ်။

---

## 🔲 ၁။ Pixel (ပစ်ဇယ်) ဆိုတာ ဘာလဲ?

ပုံတစ်ပုံကို အနီးကပ်ဆုံး (Zoom in) ချဲ့ကြည့်လိုက်မယ်ဆိုရင် လေးထောင့် အကွက်ငယ်လေးတွေ အများကြီး စုပေါင်းထားတာကို တွေ့ရပါလိမ့်မယ်။ အဲ့ဒီ အကွက်ငယ်လေး တစ်ကွက်ချင်းစီကို **Pixel (Picture Element)** လို့ ခေါ်ပါတယ်။

Pixel တစ်ခုချင်းစီမှာ **0 ကနေ 255 အထိ** တန်ဖိုး (Value) တစ်ခုစီ ရှိကြပါတယ်။
*   **`0`** ဆိုလျှင် **အမည်းရောင် (Black)** ဖြစ်ပါတယ်။
*   **`255`** ဆိုလျှင် **အဖြူရောင် (White)** ဖြစ်ပါတယ်။
*   အလယ်က ဂဏန်းတွေ (ဥပမာ - `127`) ဆိုရင်တော့ မီးခိုးရောင် (Gray) အဆင့်ဆင့် ဖြစ်သွားပါတယ်။

![Pixel Grid](https://via.placeholder.com/800x400?text=Image+Zoomed+In+%28Showing+Pixel+Grid+and+Numbers%29)
*(မှတ်ချက် - ဤနေရာတွင် ပုံတစ်ပုံကို Zoom ချဲ့၍ ဂဏန်းတန်ဖိုးများ ပြသထားသော ပုံထည့်ရန်)*

> **Image Resolution (ပုံ၏ အရွယ်အစား)**
> "ဒီပုံက `1920 x 1080` Resolution ရှိတယ်" လို့ ပြောရင်၊ အဲ့ဒီပုံမှာ အလျား (Width) က Pixel ၁၉၂၀ ရှိပြီး၊ အနံ (Height) က Pixel ၁၀၈၀ ရှိတယ်လို့ ဆိုလိုတာပါ။ စုစုပေါင်း Pixel အရေအတွက်က $1920 \times 1080 = 2,073,600$ (၂ သန်းကျော်) ရှိပါတယ်။

## 📐 ၂။ The Coordinate System (ပုံရိပ်များ၏ ဝင်ရိုးစနစ်)

ပုံတွေကို ဖြတ်တာ (Cropping) တွေ၊ ပုံပေါ်မှာ စာရေးတာတွေ လုပ်တဲ့အခါ Location (နေရာ) ကို သတ်မှတ်ဖို့ Coordinate System (x, y) ကို နားလည်ဖို့ အလွန်အရေးကြီးပါတယ်။

ကျောင်းမှာသင်ခဲ့ရတဲ့ သင်္ချာဂရပ်ဖ် (Math Graph) တွေမှာ (0,0) က ဘယ်ဘက် အောက်ထောင့်မှာ ရှိပြီး `y` ဝင်ရိုးက အပေါ်ကို သွားပါတယ်။

ဒါပေမယ့် **Computer Vision (OpenCV) မှာတော့ ပြောင်းပြန်ဖြစ်ပါတယ်။**
*   **Origin `(0, 0)`** ဟာ ပုံရဲ့ **ဘယ်ဘက် အပေါ်ထောင့် (Top-Left corner)** မှာ ရှိပါတယ်။
*   **`x` ဝင်ရိုး** က ညာဘက်ကို သွားပါတယ်။ (Width ကို ကိုယ်စားပြုပါတယ်)
*   **`y` ဝင်ရိုး** က အောက်ဘက်ကို သွားပါတယ်။ (Height ကို ကိုယ်စားပြုပါတယ်)

![OpenCV Coordinate System](https://via.placeholder.com/800x400?text=OpenCV+Coordinate+System+%28Top-Left+is+0%2C0%2C+Y+goes+Down%29)

## 🎨 ၃။ Color Channels (အရောင် လိုင်းများ)

ကွန်ပျူတာတွေဟာ ပုံတွေကို အရောင်အသွေးပေါ် မူတည်ပြီး အဓိက အားဖြင့် ၂ မျိုး ခွဲခြားသိမြင်ပါတယ်။

### (A) Grayscale Images (အဖြူအမည်း ပုံများ)
Grayscale ပုံတွေမှာ အရောင်မပါပါဘူး။ အမည်း (0) ကနေ အဖြူ (255) အထိ အလင်းအမှောင် (Intensity) ပဲ ပါပါတယ်။ ဒါကြောင့် သူ့ကို 2D Matrix (အလျား x အနံ) ဇယားကွက် တစ်ခုတည်းနဲ့ ဖွဲ့စည်းထားပါတယ်။ (Channels = 1)

### (B) Color Images (ကာလာ ပုံများ)
ကာလာပုံတွေမှာတော့ **Red (အနီ), Green (အစိမ်း), Blue (အပြာ)** ဆိုတဲ့ အခြေခံအရောင် ၃ မျိုးကို ရောစပ်ပြီး အရောင်ပေါင်း သန်းချီ ဖန်တီးထားတာ ဖြစ်ပါတယ်။ ဒါကြောင့် Color ပုံတစ်ပုံမှာ Grayscale လို ဇယားကွက် ၁ ခုတည်း မဟုတ်ဘဲ၊ R, G, B ဆိုပြီး **ဇယားကွက် (Matrix) ၃ ခု ထပ်ထားတာ** ဖြစ်ပါတယ်။ (Channels = 3)

> ⚠️ **အရေးကြီးသော မှတ်ချက် (OpenCV ၏ ထူးခြားချက်):**
> ပုံမှန်အားဖြင့် Color ပုံတွေကို `RGB` (Red-Green-Blue) လို့ သတ်မှတ်ပေမယ့်၊ **OpenCV ကတော့ ပုံတွေကို `BGR` (Blue-Green-Red) အစီအစဉ်နဲ့ ဖတ်ပါတယ်။** ဒါဟာ အလွန်အရေးကြီးတဲ့ အချက်ဖြစ်ပြီး၊ နောက်ပိုင်းမှာ OpenCV နဲ့ Matplotlib (သို့) PyTorch ကို တွဲသုံးတဲ့အခါ `BGR` ကနေ `RGB` ကို မဖြစ်မနေ ပြန်ပြောင်းပေးရလေ့ ရှိပါတယ်။

![RGB vs BGR](https://via.placeholder.com/800x400?text=Color+Image+Split+into+3+Channels+%28Red%2C+Green%2C+Blue+Matrices%29)

## 🔢 ၄။ Images as Matrices (Numpy Arrays)

Python မှာ Computer Vision ကို လုပ်တဲ့အခါ၊ ပုံတွေကို **Numpy Array (N-dimensional Array)** တွေအနေနဲ့ သိမ်းဆည်းပါတယ်။ Numpy Array ဆိုတာ Python ရဲ့ သင်္ချာ တွက်ချက်မှုဆိုင်ရာ Library တစ်ခုဖြစ်ပြီး၊ Matrix တွေကို မြန်မြန်ဆန်ဆန် တွက်ချက်ပေးနိုင်ပါတယ်။

ပုံတစ်ပုံကို Numpy Array အနေနဲ့ ဖတ်လိုက်တဲ့အခါ သူ့ရဲ့ **Shape** (အရွယ်အစား ဖွဲ့စည်းပုံ) ကို အောက်ပါအတိုင်း မြင်ရပါမယ်-

*   **Grayscale Image Shape:** `(Height, Width)` 
    *   ဥပမာ - `(1080, 1920)`
*   **Color Image Shape:** `(Height, Width, Channels)`
    *   ဥပမာ - `(1080, 1920, 3)` 
    *   ဒီနေရာမှာ `3` ဆိုတာက Blue, Green, Red ဆိုတဲ့ အရောင် ၃ လွှာကို ဆိုလိုတာပါ။

> 💡 **Beginner Pitfall (အမှားများလေ့ရှိသော အချက်):**
> ကျွန်တော်တို့က ပုံတစ်ပုံကို ပြောရင် `1920 x 1080` (Width x Height) လို့ ပြောလေ့ရှိပေမယ့်၊ Numpy array ရဲ့ Shape ကတော့ Matrix စည်းမျဉ်းအရ `(Rows, Columns)` ကို ယူတဲ့အတွက် **`(Height, Width)`** အနေနဲ့ ပြောင်းပြန် ထွက်လာတယ် ဆိုတာကို သတိပြုရပါမယ်။

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  ကွန်ပျူတာအတွက် ပုံတစ်ပုံဆိုတာ `0` ကနေ `255` အတွင်း ရှိတဲ့ **ဂဏန်းများ ဖွဲ့စည်းထားသော ဇယားကွက် (Matrix)** ဖြစ်ပါတယ်။
2.  OpenCV ရဲ့ **Origin `(0,0)` က ဘယ်ဘက်အပေါ်ထောင့်** မှာ ရှိပြီး၊ `Y` ဝင်ရိုးက အောက်ကို သွားပါတယ်။
3.  Color ပုံတွေဟာ 3D Matrix ဖြစ်ပြီး၊ OpenCV က **`RGB` အစား `BGR`** format ကို အသုံးပြုပါတယ်။
4.  Python တွင် ပုံများကို Numpy Array များအဖြစ် သိမ်းဆည်းပြီး Shape မှာ **`(Height, Width, Channels)`** ဖြစ်ပါသည်။
