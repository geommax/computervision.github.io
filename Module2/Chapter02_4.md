# 📘 Chapter 2.4: Color Spaces & Masking (အရောင်ပြောင်းလဲခြင်းနှင့် သီးသန့်အရောင် ခွဲထုတ်ခြင်း)

OpenCV က ပုံတစ်ပုံကို ဖတ်လိုက်တဲ့အခါ `BGR (Blue, Green, Red)` ဆိုတဲ့ Color Space (အရောင် ဖွဲ့စည်းပုံ) နဲ့ ဖတ်တယ်ဆိုတာကို အရင်အခန်းတွေမှာ လေ့လာခဲ့ပါတယ်။ မျက်နှာပြင်ပေါ်မှာ ပုံတွေကို ပြသဖို့အတွက် BGR က အကောင်းဆုံး ဖြစ်ပေမယ့်၊ **"ဒီပုံထဲက အပြာရောင် ကားလေးကိုပဲ ခွဲထုတ်ပေးပါ"** လို့ ကွန်ပျူတာကို ခိုင်းတဲ့အခါမှာတော့ BGR က သိပ်အဆင်မပြေတော့ပါဘူး။ 

ဘာကြောင့်လဲဆိုတော့ နေရောင်ကျနေတဲ့ အပြာရောင်နဲ့၊ အရိပ်ကျနေတဲ့ အပြာရောင်ဟာ BGR တန်ဖိုးတွေ လုံးဝကွာခြားသွားလို့ပဲ ဖြစ်ပါတယ်။ ဒါကြောင့် အရောင်တွေကို ရှာဖွေဖို့ ပိုမိုကောင်းမွန်တဲ့ **HSV Color Space** အကြောင်းနဲ့၊ ကိုယ်လိုချင်တဲ့ အရောင်ကို သီးသန့်ခွဲထုတ်မယ့် **Masking** နည်းပညာတွေကို ဒီအခန်းမှာ လေ့လာသွားပါမယ်။

## 🎨 ၁။ Color Spaces ဆိုတာ ဘာလဲ? (`cv2.cvtColor`)

Color Space ဆိုတာ ပုံတစ်ပုံမှာရှိတဲ့ အရောင်တွေကို ဂဏန်းတွေအနေနဲ့ ဘယ်လိုကိုယ်စားပြုမလဲ ဆိုတဲ့ စနစ်ဖြစ်ပါတယ်။ OpenCV မှာ အသုံးအများဆုံး Color Space ၃ မျိုး ရှိပါတယ်။

1.  **BGR (Blue, Green, Red):** မူလ Default အနေအထား။ လူတွေ မြင်ရတဲ့အတိုင်း ပြသရန် အကောင်းဆုံး။
2.  **Grayscale (အဖြူအမည်း):** အရောင်တွေ မလိုအပ်တဲ့အခါ (ဥပမာ - မျက်နှာ ရှာဖွေခြင်း၊ အနားသတ်မျဉ်း ရှာဖွေခြင်း) မှာ တွက်ချက်မှု မြန်ဆန်စေရန် ပြောင်းလဲအသုံးပြုသည်။
3.  **HSV (Hue, Saturation, Value):** အရောင်များကို ရှာဖွေခွဲထုတ်ရာတွင် အကောင်းဆုံး စနစ်။

Color Space တစ်ခုကနေ တစ်ခုကို ပြောင်းလဲဖို့ `cv2.cvtColor()` ကို အသုံးပြုပါတယ်။

```python
import cv2

image = cv2.imread('test.jpg')

# BGR မှ Grayscale သို့ ပြောင်းခြင်း
gray_image = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# BGR မှ HSV သို့ ပြောင်းခြင်း
hsv_image = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)
```

---

## 🧐 ၂။ ဘာကြောင့် အရောင်ခွဲထုတ်ဖို့ HSV ကို သုံးတာလဲ? (Why HSV?)

HSV ဆိုတာ အရောင်ကို အပိုင်း ၃ ပိုင်း ခွဲခြားထားတဲ့ စနစ်ဖြစ်ပါတယ်။
*   **H (Hue - အရောင်အသွေး):** အနီ၊ အစိမ်း၊ အပြာ စတဲ့ **"တကယ့်အရောင်"** ကို ကိုယ်စားပြုပါတယ်။ 
*   **S (Saturation - အရောင်ရင့်အား):** အရောင် ဘယ်လောက် စူးသလဲ၊ ဖျော့သလဲ ဆိုတာကို ကိုယ်စားပြုပါတယ်။
*   **V (Value - အလင်းအမှောင်):** ပုံပေါ်ကို အလင်း ဘယ်လောက်ကျနေလဲ (Brightness) ကို ကိုယ်စားပြုပါတယ်။

**အားသာချက်:** ပန်းသီးအနီရောင်ပေါ်ကို အရိပ်ကျသွားတဲ့အခါ BGR စနစ်မှာ R, G, B ဂဏန်း ၃ ခုလုံး ပြောင်းလဲသွားပါတယ်။ ဒါပေမယ့် HSV စနစ်မှာတော့ အရိပ်ကျသွားရင် **V (အလင်းအမှောင်)** သာ ပြောင်းလဲသွားပြီး၊ **H (အနီရောင်)** တန်ဖိုးကတော့ အတူတူပဲ ဆက်ရှိနေပါတယ်။ ဒါကြောင့် အလင်းအမှောင် ပြောင်းလဲမှုတွေအောက်မှာ အရောင်ကို တိတိကျကျ ရှာချင်ရင် HSV ကို ပြောင်းသုံးရခြင်း ဖြစ်ပါတယ်။

> ⚠️ **Beginner Pitfall (OpenCV ၏ Hue တန်ဖိုး):**
> ပုံမှန် Software တွေမှာ Hue တန်ဖိုးက `0 ကနေ 360` ဒီဂရီ အထိ ရှိပါတယ်။ ဒါပေမယ့် OpenCV ရဲ့ Numpy Array က 8-bit (အများဆုံး 255 သာလက်ခံနိုင်) ဖြစ်တဲ့အတွက် 360 ကို မဆံ့ပါဘူး။ ဒါကြောင့် **OpenCV မှာ Hue (H) တန်ဖိုးဟာ `0 မှ 179` အထိသာ ရှိပါတယ်။**

## 🎭 ၃။ Color Masking (သတ်မှတ်ထားသော အရောင်ကိုသာ စစ်ထုတ်ခြင်း)

ပုံထဲကနေ ကိုယ်လိုချင်တဲ့ အရောင်ကို စစ်ထုတ်ဖို့ (Mask လုပ်ဖို့) `cv2.inRange()` ကို အသုံးပြုရပါတယ်။
ဥပမာ - ပုံထဲက **အပြာရောင် (Blue)** အရာဝတ္ထုကိုပဲ သီးသန့် ခွဲထုတ်ကြည့်ပါမယ်။

```python
import cv2
import numpy as np

# ၁။ ပုံကို ဖတ်ပြီး HSV ပြောင်းမည်
image = cv2.imread('shapes.jpg')
hsv_image = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

# ၂။ အပြာရောင်အတွက် အနိမ့်ဆုံး နှင့် အမြင့်ဆုံး တန်ဖိုးများ သတ်မှတ်မည် (H, S, V)
# (အပြာရောင်၏ Hue သည် 110 မှ 130 ကြားတွင် ရှိလေ့ရှိသည်)
lower_blue = np.array([100, 50, 50])
upper_blue = np.array([130, 255, 255])

# ၃။ Mask (စစ်ထုတ်ဇကာ) ပြုလုပ်ခြင်း
mask = cv2.inRange(hsv_image, lower_blue, upper_blue)
```

**Mask ၏ အလုပ်လုပ်ပုံ:**
`cv2.inRange()` က ပုံထဲမှာရှိတဲ့ Pixel တွေကို တစ်ခုချင်းစီ စစ်ဆေးပါတယ်။ သတ်မှတ်ထားတဲ့ H,S,V Range ထဲမှာ ဝင်နေရင် အဲ့ဒီ Pixel ကို **အဖြူရောင် (255)** ပြောင်းလိုက်ပြီး၊ Range ထဲ မဝင်တဲ့ ကျန်တဲ့ အရောင်တွေ အားလုံးကို **အမည်းရောင် (0)** အဖြစ် ပြောင်းပစ်လိုက်ပါတယ်။ ရလဒ်အနေနဲ့ အဖြူနဲ့အမည်းသာ ပါဝင်တဲ့ Mask ပုံတစ်ပုံ ထွက်လာပါမယ်။

---

## ✂️ ၄။ မူရင်းပုံနှင့် ပြန်လည်ပေါင်းစပ်ခြင်း (Bitwise Operations)

Mask လုပ်လိုက်လို့ ရလာတဲ့ ပုံဟာ အဖြူနဲ့ အမည်းပဲ ဖြစ်နေပါတယ်။ ငါတို့လိုချင်တဲ့ အပြာရောင် အရာဝတ္ထုရဲ့ "အစစ်အမှန်အရောင်" တွေကို ပြန်လိုချင်တယ်ဆိုရင် မူရင်းပုံနဲ့ Mask ပုံကို **Bitwise AND (`cv2.bitwise_and`)** အသုံးပြုပြီး ထပ်ပေးရပါတယ်။

```python
# မူရင်းပုံ (image) ကို mask နှင့် ထပ်၍ ဖြတ်ယူခြင်း
result = cv2.bitwise_and(image, image, mask=mask)
```
*(ရှင်းလင်းချက် - Mask မှာ အဖြူရောင်ဖြစ်နေတဲ့ နေရာတွေကိုပဲ မူရင်းပုံကနေ ယူလိုက်ပြီး၊ အမည်းရောင်ဖြစ်နေတဲ့ နေရာတွေကိုတော့ အမည်းရောင်အတိုင်း ချန်လှပ်ထားခဲ့တာ ဖြစ်ပါတယ်။)*

---

## 🧩 ၅။ အစအဆုံး ပေါင်းရေးကြည့်ခြင်း (Complete Example: Blue Object Extractor)

```python
import cv2
import numpy as np

def main():
    # ၁။ ပုံဖတ်ခြင်း
    image = cv2.imread('test.jpg') # ပုံထဲတွင် အပြာရောင်အရာဝတ္ထု ပါဝင်ရမည်
    if image is None:
        print("Image not found!")
        return

    # ပုံကို ကြည့်ရလွယ်အောင် အနည်းငယ် သေးလိုက်မည်
    image = cv2.resize(image, (640, 480))

    # ၂။ BGR မှ HSV သို့ ပြောင်းခြင်း
    hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

    # ၃။ အပြာရောင် Range သတ်မှတ်ခြင်း
    lower_blue = np.array([100, 150, 50]) # S နှင့် V ကို အနည်းငယ်မြှင့်ထားသည်
    upper_blue = np.array([140, 255, 255])

    # ၄။ Mask ဖန်တီးခြင်း (အဖြူ/အမည်း ပုံထွက်လာမည်)
    mask = cv2.inRange(hsv, lower_blue, upper_blue)

    # ၅။ မူရင်းပုံနှင့် Mask ကို Bitwise AND လုပ်၍ ပေါင်းစပ်ခြင်း
    result = cv2.bitwise_and(image, image, mask=mask)

    # ၆။ ရလဒ်များကို နှိုင်းယှဉ်ပြသခြင်း
    cv2.imshow('1. Original Image', image)
    cv2.imshow('2. Blue Mask (B&W)', mask)
    cv2.imshow('3. Final Result', result)

    cv2.waitKey(0)
    cv2.destroyAllWindows()

if __name__ == "__main__":
    main()
```
*(ဒီ Code ကို Run ကြည့်လိုက်ရင် Window ၃ ခု တက်လာပါမယ်။ ဒုတိယ Window မှာ အပြာရောင်ရှိတဲ့ နေရာတွေက အဖြူဖြစ်နေပြီး၊ တတိယ Window မှာတော့ တခြား နောက်ခံတွေ အားလုံး အမည်းရောင်ဖြစ်သွားပြီး အပြာရောင် အရာဝတ္ထုလေးကိုပဲ ကွက်ကွက်ကွင်းကွင်း မြင်ရပါလိမ့်မယ်။)*

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **`cv2.cvtColor()`** - ပုံ၏ Color Space များကို ပြောင်းလဲရန် အသုံးပြုသည်။
2.  **HSV Space** - အလင်းအမှောင် (Value) နှင့် အရောင် (Hue) ကို သီးခြားစီခွဲထားသောကြောင့် အရောင်များကို ရှာဖွေရန်အတွက် BGR ထက် ပိုမိုသင့်လျော်သည်။ (OpenCV တွင် Hue Range သည် `0-179` ဖြစ်သည်)။
3.  **`cv2.inRange()`** - သတ်မှတ်ထားသော အရောင် Range ကြားတွင် ရှိ/မရှိ စစ်ဆေးပြီး အဖြူနှင့်အမည်း Mask တစ်ခု ဖန်တီးပေးသည်။
4.  **`cv2.bitwise_and()`** - Mask ပုံကို အသုံးပြု၍ မူရင်းပုံထဲမှ လိုချင်သော အစိတ်အပိုင်းကိုသာ ဖြတ်ထုတ်ယူသည်။
