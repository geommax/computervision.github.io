# 📘 Chapter 2.2: Basic OpenCV Operations (ပုံများကို ဖတ်ခြင်း၊ ပြသခြင်း၊ သိမ်းဆည်းခြင်း)

Computer Vision Project တိုင်းဟာ ပုံတစ်ပုံ (သို့မဟုတ်) ဗီဒီယိုတစ်ခုကို ကွန်ပျူတာထဲ ဖတ်သွင်းခြင်းကနေ စတင်ပါတယ်။ ဒီအခန်းမှာတော့ OpenCV Library ကို အသုံးပြုပြီး ပုံတွေကို ဖတ်တာ၊ မျက်နှာပြင်ပေါ်မှာ ပြသတာ နဲ့ ပြင်ဆင်ပြီးသား ပုံတွေကို ပြန်လည်သိမ်းဆည်းတာ (I/O Operations) တွေကို အခြေခံကျကျ လေ့လာသွားပါမယ်။

## 📥 ၁။ ပုံများကို ဖတ်သွင်းခြင်း (`cv2.imread`)

OpenCV မှာ ပုံတစ်ပုံကို ဖတ်ဖို့အတွက် `cv2.imread()` ဆိုတဲ့ Function ကို အသုံးပြုပါတယ်။ 

```python
import cv2

# ပုံကို ဖတ်သွင်းခြင်း (ပုံအမည် သို့မဟုတ် ပုံရှိရာ လမ်းကြောင်းကို ထည့်ပါ)
image = cv2.imread('test.jpg')

# ပုံကို သေချာဖတ်မိရဲ့လား စစ်ဆေးခြင်း
if image is None:
    print("❌ အမှား: ပုံကို ရှာမတွေ့ပါ။ လမ်းကြောင်းမှန်ကန်မှုရှိမရှိ စစ်ဆေးပါ။")
else:
    print("✅ ပုံကို အောင်မြင်စွာ ဖတ်သွင်းပြီးပါပြီ။")
```

> 💡 **Beginner Pitfall (အမှားများလေ့ရှိသော အချက်):**
> OpenCV မှာ `imread()` က ပုံကို ရှာမတွေ့ရင် Error မတက်ပါဘူး။ အဲ့ဒီအစား `None` ဆိုတဲ့ တန်ဖိုးကိုပဲ ပြန်ပေးပါတယ်။ ဒါကြောင့် ပုံကို တကယ်ဖတ်မိရဲ့လားဆိုတာ အမြဲတမ်း `if image is None:` နဲ့ စစ်ဆေးလေ့ရှိပါတယ်။

**ပုံဖတ်ရာတွင် အသုံးပြုနိုင်သော Mode များ (Flags)**
ပုံကို ဖတ်တဲ့အခါ မူလအရောင်အတိုင်း မဖတ်ဘဲ အဖြူအမည်းအနေနဲ့ တန်းဖတ်ချင်ရင် ဒုတိယ parameter အနေနဲ့ Flag တွေ ထည့်ပေးလို့ ရပါတယ်။
*   `cv2.IMREAD_COLOR` (သို့မဟုတ်) `1` : ကာလာပုံအတိုင်း ဖတ်ရန် (Default)။
*   `cv2.IMREAD_GRAYSCALE` (သို့မဟုတ်) `0` : အဖြူအမည်းပုံ အဖြစ် ပြောင်း၍ ဖတ်ရန်။

```python
# အဖြူအမည်းပုံ အဖြစ် တိုက်ရိုက်ဖတ်ခြင်း
gray_image = cv2.imread('test.jpg', 0)
```

## 🔍 ၂။ ပုံ၏ အချက်အလက်များ စစ်ဆေးခြင်း (Image Properties)

Chapter 2.1 မှာ သင်ခဲ့တဲ့အတိုင်း OpenCV က ဖတ်လိုက်တဲ့ ပုံဟာ **Numpy Array** ကြီးတစ်ခု ဖြစ်သွားပါတယ်။ သူ့ရဲ့ အချက်အလက်တွေကို `.shape` နဲ့ `.dtype` ကို သုံးပြီး စစ်ဆေးကြည့်ပါမယ်။

```python
import cv2

image = cv2.imread('test.jpg')

# ပုံ၏ အရွယ်အစားနှင့် Channel ကို စစ်ဆေးခြင်း
print("Shape of the image:", image.shape) 
# Output ဥပမာ: (1080, 1920, 3) -> (Height, Width, Channels)

# စုစုပေါင်း Pixel အရေအတွက်
print("Total number of pixels:", image.size)

# Data Type ကို စစ်ဆေးခြင်း
print("Data Type:", image.dtype) 
# Output: uint8 (Unsigned Integer 8-bit, ဆိုလိုသည်မှာ 0 မှ 255 ထိသာ ရှိသည်)
```

## 🖼️ ၃။ ပုံကို မျက်နှာပြင်တွင် ပြသခြင်း (`cv2.imshow`)

ပုံကို ဖတ်ပြီးသွားရင် မျက်နှာပြင်ပေါ်မှာ Window လေးတစ်ခုနဲ့ ပေါ်လာအောင် `cv2.imshow()` ကို အသုံးပြုပါတယ်။ ဒါပေမယ့် `imshow` တစ်ခုတည်း သုံးလို့မရပါဘူး။ Window ကြီး ချက်ချင်း ပိတ်မသွားအောင် `cv2.waitKey()` ဆိုတဲ့ Function ပါ တွဲသုံးပေးရပါတယ်။

```python
import cv2

image = cv2.imread('test.jpg')

# မျက်နှာပြင်တွင် ပြသခြင်း (ပထမဆုံး Parameter သည် Window ၏ နာမည်ဖြစ်သည်)
cv2.imshow('My First Image View', image)

# ကီးဘုတ်မှ တစ်ခုခု နှိပ်သည်အထိ (သို့မဟုတ် Window ပိတ်သည်အထိ) စောင့်နေရန်
cv2.waitKey(0)

# ဖွင့်ထားသော Window များအားလုံးကို ပြန်ပိတ်ရန် (Memory ရှင်းလင်းရန်)
cv2.destroyAllWindows()
```

> **`cv2.waitKey()` ၏ အလုပ်လုပ်ပုံ:**
> *   `cv2.waitKey(0)` ဟာ ကီးဘုတ်ကနေ ခလုတ်တစ်ခုခု မနှိပ်မချင်း Window ကို အချိန်အကန့်အသတ်မရှိ ဆက်ဖွင့်ထားပေးပါတယ်။
> *   အကယ်၍ `cv2.waitKey(5000)` လို့ ရေးရင် 5000 milliseconds (၅ စက္ကန့်) ကြာရင် အလိုအလျောက် ပိတ်သွားမှာ ဖြစ်ပါတယ်။
> *   Video တွေ၊ Webcam တွေ သုံးတဲ့အခါမှာတော့ Frame တစ်ခုနဲ့ တစ်ခုကြား စောင့်ဖို့ `cv2.waitKey(1)` ကို အသုံးများပါတယ်။

## 💾 ၄။ ပုံများကို ပြန်လည်သိမ်းဆည်းခြင်း (`cv2.imwrite`)

ကိုယ်လိုချင်တဲ့ အဖြူအမည်းပြောင်းတာတွေ၊ စာသားတွေ ရေးထည့်တာတွေ လုပ်ပြီးသွားရင် အဲ့ဒီ Numpy Array ကြီးကို ပုံ (File) တစ်ခု အနေနဲ့ Storage ထဲ ပြန်သိမ်းဖို့ လိုအပ်ပါတယ်။ အဲ့ဒီအတွက် `cv2.imwrite()` ကို အသုံးပြုပါတယ်။

```python
import cv2

# ပုံကို အဖြူအမည်းအနေဖြင့် ဖတ်ပါ
gray_image = cv2.imread('test.jpg', 0)

# ပုံကို Storage ထဲသို့ ပြန်သိမ်းပါ (ကိုယ်လိုချင်သော Format ဖြင့် သိမ်းနိုင်သည်)
success = cv2.imwrite('output_gray.png', gray_image)

if success:
    print("✅ ပုံကို 'output_gray.png' အမည်ဖြင့် အောင်မြင်စွာ သိမ်းဆည်းပြီးပါပြီ။")
```

`cv2.imwrite()` က ပုံကို သိမ်းပေးရုံသာမက မိမိပေးလိုက်တဲ့ Extension (ဥပမာ- `.jpg`, `.png`) အပေါ်မူတည်ပြီး အလိုအလျောက် Format ပြောင်းပေးတဲ့ စွမ်းရည်လည်း ရှိပါတယ်။

## 🧩 ၅။ အစအဆုံး ပေါင်းရေးကြည့်ခြင်း (Complete Example)

အပေါ်မှာ သင်ခဲ့တာတွေ အားလုံးကို စုစည်းပြီး Script တစ်ခုတည်းအနေနဲ့ ရေးကြည့်ကြရအောင်။

```python
import cv2

def main():
    # ၁။ ပုံကို ဖတ်ခြင်း
    image = cv2.imread('test.jpg')
    
    if image is None:
        print("Error: Image not found!")
        return

    # ၂။ အချက်အလက်များ ထုတ်ပြခြင်း
    print("Image Shape:", image.shape)

    # ၃။ မျက်နှာပြင်တွင် ပြသခြင်း
    cv2.imshow('Original Image', image)
    
    # ၄။ ကီးဘုတ်မှ ခလုတ်တစ်ခုခု နှိပ်သည်အထိ စောင့်ခြင်း
    cv2.waitKey(0)
    cv2.destroyAllWindows()

    # ၅။ ပုံကို Format အသစ်ဖြင့် ပြန်သိမ်းခြင်း
    cv2.imwrite('test_copy.png', image)
    print("Image saved as test_copy.png successfully!")

if __name__ == "__main__":
    main()
```

## 📝 အနှစ်ချုပ် (Key Takeaways)
1.  **`cv2.imread('path')`** - ပုံကို Matrix (Numpy Array) အနေနဲ့ ဖတ်သွင်းပေးပါတယ်။ ရှာမတွေ့ရင် `None` ပြန်ပေးပါတယ်။
2.  **`image.shape`** - ပုံရဲ့ `(Height, Width, Channels)` ကို သိရှိနိုင်ပါတယ်။
3.  **`cv2.imshow('title', img)`** - ပုံကို Window နဲ့ ပြသပေးပါတယ်။
4.  **`cv2.waitKey(0)`** - ဖွင့်ထားတဲ့ Window ချက်ချင်း ပိတ်မသွားအောင် ထိန်းထားပေးပါတယ်။
5.  **`cv2.imwrite('path', img)`** - Matrix များကို Image File အနေဖြင့် ကွန်ပျူတာထဲ ပြန်သိမ်းပေးပါတယ်။
